The shared core is byte-identical to the validated IEEE8500 implementation. It groups the complete connected-MESS Cartesian grid by the unchanged Q-deviation objective, completes the first feasible shell, applies the original lexicographic tie-break, and runs the inherited local SLSQP refinement separately. There is no global candidate/time cap.

After the new campaign's remapped electrical/input/output binding has been released, call `activate.activate(robust_search_module, frozen_worker_module)` immediately after loading the frozen numerical modules and before calling the Actual worker. This rebinds only `correct_slot`; it retains the original full chronological PrefixEngine and runner bytecode. Historical worker snapshots are unchanged. The activation hook itself performs no replay or production execution.

Run `python -B preflight.py` for the legacy runner/engine binding, four-resource/625-domain, and shared-code SHA checks. This is a software binding preflight, not a fresh AC test of the new IEEE123 mapping. The inherited campaign-readiness stop gate remains applicable. No IEEE123 production was started by this change.
