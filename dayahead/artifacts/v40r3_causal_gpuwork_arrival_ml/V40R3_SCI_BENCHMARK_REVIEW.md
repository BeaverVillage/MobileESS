# V40R3 literature and benchmark review

This review precedes all fitting. CMABF is a working name, with no established novelty or superiority. V40R3 predicts incremental arriving observed GPU-service demand; the execution schedule belongs to the later optimizer.

| Research issue / benchmark | Primary, peer-reviewed source | Fit to this experiment and limitations |
|---|---|---|
| Intermittent and sparse demand | [Türkmen et al., PLOS ONE, 2021, deep renewal processes](https://doi.org/10.1371/journal.pone.0259764) | Occurrence and positive-size modeling already have substantial prior art. The 38.32% zero fraction motivates testing a two-part model here, but does not establish that it will outperform a direct model. Renewal event models concern demand arrivals, making them closer to this estimand than historical execution occupancy. |
| Scope of intermittent forecasting | [Nikolopoulos, EJOR, 2021](https://www.sciencedirect.com/science/article/pii/S0377221720300308) | Intermittent methods extend beyond spare-parts inventory. This supports including an occurrence/magnitude benchmark; it does not prove that workload service demand is independent or identically distributed. |
| Probabilistic intermittent combinations | [Wang, Kang and Petropoulos, EJOR, 2024](https://doi.org/10.1016/j.ejor.2024.01.032) | Uncertainty concerns both demand size and its occurrence. Strong probabilistic baselines are required; merely naming a hurdle network is not a research contribution. |
| B0 zero and B1 seasonal naive | [Petropoulos et al., *Forecasting: theory and practice*, IJF, 2022](https://doi.org/10.1016/j.ijforecast.2021.11.001) | Transparent references are indispensable. B1 uses only mature same-slot profiles at 7/14/21/28-day lags. Missing historical profiles remain unavailable; an explicitly frozen all-unavailable fallback is zero. B0 is exactly zero and never inherits legacy K5B2 predictions. |
| B2 causal LightGBM quantile | [Ke et al., NeurIPS, 2017](https://proceedings.nips.cc/paper/2017/hash/6449f44a102fde848669bdd9eb6b76fa-Abstract.html) | Strong tabular nonlinear learning with common history/context inputs and global horizon features. Separate Q50/Q90 heads are incremental heads, not independent cumulative forecasts. The original method paper is not evidence of workload forecasting accuracy. |
| B3 hurdle LightGBM | Same boosting reference plus intermittent-demand literature above | Binary occurrence and a preregistered positive-quantile grid make a strong non-neural comparator to CMABF. Unconditional quantiles must use the mixture CDF, not probability times positive Q90. |
| B4 XGBoost quantile | [Chen and Guestrin, KDD, 2016](https://doi.org/10.1145/2939672.2939785) | A separate boosting implementation is useful against implementation-specific gains. Quantile regression is supported by the pinned modern library; see [official XGBoost 3.0.5 quantile documentation](https://xgboost.readthedocs.io/en/release_3.0.0/python/examples/quantile_regression.html). CPU histogram execution preserves the model family and budget. |
| B5 Temporal Fusion Transformer | [Lim et al., IJF 37(4), 1748–1764, 2021](https://www.sciencedirect.com/science/article/pii/S0169207021000637) | The distinction between observed history and known-future covariates matches the causal input contract. Use the actual pinned TFT implementation with variable selection, gating, recurrent processing and attention. The target history is sanitized before entry; missing labels never become observed values. |
| B6 DeepAR | [Salinas et al., IJF 36(3), 1181–1191, 2020](https://www.sciencedirect.com/science/article/pii/S0169207019301888) | Autoregressive probabilistic forecasting provides a different trajectory model. The pinned upstream implementation trains a conditional Gaussian likelihood; forecasts use generated rollouts only. Because GPUh is continuous and nonnegative with zeros, negative Gaussian forecast samples are censored at zero by a frozen rule. This is a pragmatic misspecification and must be disclosed. No teacher-forced validation metric is reported. The six-hour issue-to-operating-day gap is represented in known lead context; there is no observed bridge sequence. |
| B7 N-HiTS | [Challu et al., AAAI 37(6), 6989–6997, 2023](https://ojs.aaai.org/index.php/AAAI/article/view/25854) | Hierarchical interpolation and multiple temporal resolutions form an additional strong multi-horizon benchmark. The pinned upstream implementation supports covariates and quantile loss. Backcast reconstruction loss is disabled because immature target positions are placeholders. |
| HPC arrival characteristics | [*Distributed multipliers in MWM for analyzing job arrival processes in massive HPC workload datasets*, Future Generation Computer Systems, 2014](https://www.sciencedirect.com/science/article/abs/pii/S0167739X13002732) | Arrival-process dependence and workload variability motivate temporal history and blocked evaluation. Job-arrival count studies do not directly establish GPU-service-demand forecasting performance; runtime maturity is an additional measurement issue here. |
| Probabilistic load evaluation | [Hong and Fan, IJF 32(3), 914–938, 2016](https://www.sciencedirect.com/science/article/pii/S0169207015001508) | Calibration, accuracy and downstream operational value require separate evaluation. GPUh is a service-demand proxy, not electrical load, FLOPs or hardware-independent work. No power-flow result is produced in this revision. |
| Score interpretation | [Gneiting and Raftery, JASA, 2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf) | Distributional evaluation requires properly interpreted scores. Burst-weighted training objectives may shift nominal quantiles; independent unweighted coverage and pinball metrics remain mandatory. Summing marginal Q90 values does not generally yield the Q90 of a sum. |

## Architecture decision after the target audit

There are 167 mature training days, with 48 target increments per day and 336 past half-hour positions. A small dual-stream temporal convolutional encoder is selected for CMABF: one stream processes recent submission activity/calendar, the other mature GPUh/maturity information. Gated fusion and a shared 48-horizon decoder combine the histories with known future context. Four dilated residual blocks and pooled history avoid a large attention model on this modest number of independent days. This is a design hypothesis, not a claim that TCN is empirically superior.

The positive distribution uses a monotone quantile grid and an explicit atom at zero. The architecture is frozen before results. The secondary ablations remove maturity modeling, hurdle decomposition, or burst weighting one at a time. Removing maturity modeling never authorizes reading an immature label: the hard data sanitation rule remains in every ablation.

## Fairness and causal adaptations

All models receive the same source information: sanitized seven-day history and identical known-future/mature-seasonal context. Trees flatten that history; deep models retain the sequence. TFT, DeepAR and N-HiTS use the pinned `pytorch-forecasting==1.5.0` implementations. CMABF is independently implemented in V40R3; V40R2 code, target and feature matrices are not reused.

Two preregistered hyperparameter trials are allowed per ML family. Every deep family has the same batch size, epoch ceiling, stopping patience, seed and repeat policy. CMABF does not receive additional primary-model trials through its ablations. All models share target maturity exclusions and the same chronological blocks.

A common calibration rule for nonzero predictors may produce deliberately conservative Q90 safety forecasts. Its residual quantile is learned only in the frozen calibration block; no test residual controls it. Raw and calibrated forecasts are both retained, and empirical overcoverage is reported. Coverage in unseen temporal blocks is not guaranteed by calibration.

## Literature limits

These papers justify strong comparisons and identify existing related ideas. This review does not establish an exhaustive novelty claim for CMABF. No paper overrides the source-availability audit. With no untouched confirmation block, a positive experimental result can be described only as PREVALIDATED.
