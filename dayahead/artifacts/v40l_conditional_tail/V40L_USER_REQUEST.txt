4. RESIDUAL TARGET
============================================================

기본 residual:

    r_i = T_actual,i - T_K0,i

중요:

tail model training에 사용할 residual은
in-sample K0 residual이어서는 안 된다.

historical training rows에는 반드시
blocked / rolling OOF K0 prediction을 사용한다.

즉:

    r_i^OOF = T_actual,i - T_K0,i^OOF

self-fit leakage 금지.

기존 V40K OOF residual authority가 정확히 존재하면
SHA와 temporal provenance를 검증해 재사용 가능.
