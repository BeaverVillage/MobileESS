7. PRIMARY RISK IS POSITIVE UNDERPREDICTION
============================================================

Do NOT focus only on absolute runtime length.

The operationally dangerous event is:

actual runtime
>
safe predicted runtime

Define for job j:

e_j^+ =
max(
    T_actual,j - T_pred,j^safe,
    0
)

GPU-weighted error mass:

M_j =
g_j * e_j^+

This is important because:

a long job predicted reasonably well
is less dangerous than

a medium job predicted far too short.

All tail diagnostics must report BOTH:

- absolute long-runtime tail
- positive-underprediction tail
