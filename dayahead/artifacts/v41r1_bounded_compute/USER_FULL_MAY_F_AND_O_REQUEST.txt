# 6. FIX-AND-OPTIMIZE DEFINITION
# ============================================================

Let x* be the current complete feasible incumbent.


At iteration r choose a neighborhood N_r.


Variables associated with N_r:

FREE

FIXED to the current incumbent x*


Then solve the ORIGINAL scientific model restricted to that
neighborhood.


All original physical constraints remain active.


Conceptually:

x_j = x*_j    for j not in N_r

x_j free      for j in N_r


subject to the complete original:

- rack
- WAN
- job state
- migration
- H4
- electrical
- MESS
- policy

constraints.


This is a search restriction for one iteration.
