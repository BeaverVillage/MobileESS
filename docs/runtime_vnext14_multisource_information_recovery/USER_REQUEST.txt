12. SEMANTIC FEATURE REPRESENTATION
============================================================

Do NOT feed arbitrary raw 4096-dimensional vectors directly into the hazard
model without a frozen preprocessing contract.

Use exactly one primary dimensionality-reduction configuration:

SEM_SVD32

Procedure for each temporal fold:

1. use only TRAIN-mapped embedding rows
2. convert embedding vector to float32
3. normalize if required by documented embedding semantics
4. fit 32-component TruncatedSVD / equivalent deterministic linear reducer
   on TRAIN only
5. transform TRAIN / VALID
6. never fit reducer using VALID
7. save reducer and hash

No search over:
8/16/32/64/128 dimensions.

32 is frozen before evaluation.

If SVD is numerically inappropriate for the dense normalized embedding,
use IncrementalPCA32, but choose based on implementation/data geometry
BEFORE any VALID metric is inspected.

Document the decision.
