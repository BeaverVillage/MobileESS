## Problem and result

V42 needs separate temporal, pre-start placement and checkpoint-migration capabilities, with the optimizer selecting a joint action rather than a predetermined FLEX percentage. This independent prototype implements those masks, eight complete action classes, full-service carry-out accounting and a bounded one-hot AIDC MILP with primary line loading and secondary intervention ordering.

**Native promotion is blocked.** The final continuous service/carry-over contract and native backend are not ready; PR79 reference resource conflicts and original request-version provenance remain unresolved. No final temporal rule or executable population percentage is frozen (`NONE`, `AIDC_MILP_JOINT_ACTION_READY=false`). Existing P2 is retained because hard uncertainty-reserve feasibility is unproven. The current generic MESS implementation is MISOCP and is unchanged.
