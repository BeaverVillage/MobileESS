# Objective proposal and bounded implementation

Primary: minimize maximum normalized critical **line** loading over the supported electrical horizon. Transformer limits are separate hard rows, as in the audited V41 grid. Voltage, thermal, transformer, service, GPU/rack, WAN and existing MESS SOC/PCS/mobility remain hard physical constraints. A D-day electrical kernel makes no post-H security claim; full compute/carry-out resource reservations still remain.

After obtaining rho*, require rho≤rho*+1e−7. This is the preregistered inherited V42 block no-regret tolerance, used only by this isolated solver. No native trust/epsilon file is edited. Require a certified optimum for each bounded canary pass; timeout is unresolved, never a license to loosen constraints.

If required reserve shortfall exists, minimize it next. Known-job full service is hard, but native uncertainty reserve feasibility has not been proven hard. Native P2 is therefore retained. In the canary a required-shortfall option-cost fixture explicitly verifies that it precedes intervention. It is not a replacement for native H4 equations.

Then use migration count → shift magnitude → pre-start site-change count → MESS movement burden → deterministic tie. No arbitrary weighted sum. MESS is fixed in an A block, so its movement burden is constant there. The proposed M-block adapter must use the same primary and reserve locks followed by movement burden while AIDC action metrics are fixed. This task does not implement or certify a new M block. The alternating A1→M1→A2→M2 structure is unchanged.

One-hot complete options choose start/site/migration jointly; no action category is selected first. Singleton jobs contribute constants. The solver enforces coupled full-tail GPU capacity, WAN link payload/capacity and network-wide active-transfer limit. The affine grid test contract supplies line, voltage and transformer hard rows. Synthetic grid coefficients are explicitly labeled and are not used on Kestrel or IEEE networks.

`PRIMARY_ONLY_DEGENERACY_AUDIT.json` constructs two feasible schedules with equal rho=0.54: STAY and SHIFT_PREPLACE_MIGRATE. Both retain the same six compute slots, but the latter shifts, relocates and migrates unnecessarily under that constant-cost synthetic grid. The secondary chooses STAY. This proves primary-only underdetermination in a bounded example; it does not quantify a native campaign benefit.

The final deterministic tie uses per-job option rank locks, avoiding equal weighted-sum rank collisions. It is an implementation reproducibility device, not a scientific objective contribution. The proposed scientific statement is primary worst-line loading, secondary necessary service/reserve and then least intervention. Native production adoption remains blocked.
