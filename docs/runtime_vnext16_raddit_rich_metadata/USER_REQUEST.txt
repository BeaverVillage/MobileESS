12. RADDIT-STYLE CAUSAL NEAREST-NEIGHBOR FEATURES
============================================================

RADDiT's core idea uses similarity to historical jobs.

Implement a fully reproducible, causal version.

For query job j at submit time t_j:

eligible neighbors i must satisfy:

    end_time_i < submit_time_j

This is stricter than merely submit_time_i < submit_time_j.

The target outcome of every neighbor must already be known.

Construct similarity using ONLY approved submission metadata.

Possible representation:

    field-prefixed categorical token hashing
    +
    modules/conda multi-hot tokens
    +
    resource-request normalized features

Use deterministic nearest-neighbor search.

For k in a small preregistered set, e.g.

    k = 16, 64

do not tune after seeing validation.

Neighbor-derived Runtime features:

    neighbor_runtime_Q50
    neighbor_runtime_Q75
    neighbor_runtime_Q90
    neighbor_runtime_mean_log
    neighbor_long4h_fraction
    neighbor_long12h_fraction
    neighbor_support_count
    nearest_similarity
    mean_similarity

All statistics must come from completed historical neighbors only.
