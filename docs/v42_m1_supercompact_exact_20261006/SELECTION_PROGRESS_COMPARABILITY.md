# Matched-progress interpretation

This records the preregistered >=20% matched root time/Work rule before C1 has
completed and before the C2 arm begins. It changes no matrix, start, solver
setting, experiment budget or mathematical threshold.

C1 (compact plus scientific reductions) is the primary compact comparator for
C2's extra static presolve. If C0 fails to finish root, its unavailable root
completion time/Work cannot enter a matched comparison. C1 and C2 completed
root measurements can still be compared at their same first optimal root
callback and root-completion log milestone. C2 must improve a completed C1
milestone by at least20%; an unfinished baseline does not become a fabricated
matched time/Work. The alternative major root-completion gate requires C2
completion while both C0 and C1 fail. The strongest observed valid LB/gap and
genuine node progress remain separate selection tests. All outcomes are
reported, including conservative native runner gate values and final adjudication.
