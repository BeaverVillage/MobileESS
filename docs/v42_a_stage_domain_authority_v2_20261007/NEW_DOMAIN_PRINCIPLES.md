# Scientific domain versus active model

`v42_a_stage_domain_v2.domain.physical_domain` defines scientific membership.
`prepare_active` preserves frozen jobs, service, bounds' completion ceiling,
resources, raw Runtime metadata and exact class members. Proven histogram scopes
activate full STAY; singleton mixed graphs keep inherited STAY and valid anchors,
with all remaining physical STAY choices lazy. Inherited migration is retained.
`activate_stay` and `activate_migration` expand existing graph rows using hard-valid lazy
Options; it has no grid-score, R0-distance or certificate-sign rejection.

The physical interval is `[max(submit,event,independent hard_release),
latest_completion-service_slots]`. No historical allowed-start lower endpoint
or reference start is promoted to a hard rule. Known unprotected PENDING jobs
use this rule globally. Protected/high/urgent/unknown arrivals and fixed RUNNING
history retain frozen timing/action authority. No new live/unknown temporal
authority is manufactured.

A_NOFLEX assigns the same jobs at reference start/site with flexibility off.
Its anchor is validated independently using the same service and resources.
If it is physically valid it is always in flexible STAY support. This proves
nesting of the no-flex feasible set under identical global coefficients; it
does not prove that A_NOFLEX itself is globally feasible.

R0 remains the reference for P2 displacement and no-action metadata. Historical
shift coefficients were `start-reference >= 0`; their intended magnitude is
extended by absolute value for newly admitted earlier starts. Every old-domain
coefficient is unchanged. Earlier starts cannot earn negative intervention cost.
CC4 deviation, migration count and prestart count retain their original mapping.

Complete STAY histogram replacement is rejected for singleton mixed migration
flow LPs by an exact rational counterexample. Existing compact histogram classes
remain exact and compact; singleton mixed graphs preserve their inherited LP.
Complete scientific STAY support is wider than the old model. No speed claim is
made for May10/12 or the unresolved May19 scientific domain.

Migration block timestamps are losslessly retained, not merged as equivalent
scientific columns. Payload, path, physical checkpoint seconds, restart, service
remaining, carryout, Runtime and grid mapping come from unchanged authority.
Even low-priority paths remain scientific members.

Feasibility rescue requires independently verified exact Farkas evidence.
Improvement search uses distinct objective/dual evidence on a feasible restricted
model. Unsupported/incomplete evidence means UNKNOWN. A complete physical path
scan alone does not cover native mixed-flow LP directions; LP closure additionally
requires independently verified exact-master/native-projection coverage. Root LP pricing never
proves full integer closure. Final production needs full finite activation or
exact branch-and-price/another independently valid integer closure certificate.
