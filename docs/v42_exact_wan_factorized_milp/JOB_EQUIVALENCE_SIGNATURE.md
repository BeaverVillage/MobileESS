# Exact job coefficients
The signature includes every Job dataclass field except UID, every ServiceBoundary field, immutable Resources identity, Runtime completion offset (risk nominal completion minus reference end), survival kernel, gamma90, GPU/site/time power interface and objective reference fields. Thus state, duration, GPU gang, start window/reference, sites, QoS/protection, unknown arrivals, checkpoint phase/capability, migrations_used, residency/rack restrictions, latest service completion, WAN payload/pairs and scientific coefficients participate.

PR99 also preserves the deterministic physical-event tie objective. Its coefficients have a global job-order offset, with different event counts along STAY and migrated paths. Actual event rank offset is included, rather than UID text. Consequently scientific-domain template reuse does not automatically imply interchangeability under every preserved objective. The audited full-objective classes are singleton; no aggregation or individual decomposition claim is made. Counts/signature digests are in JOB_EQUIVALENCE_AUDIT.json.

The auxiliary audit excluding ONLY the original deterministic event-rank tie identifies 117 exact six-scientific-objective/domain coefficient classes. This distinguishes actual scientific interchangeability from job-specific rank offsets; UID itself is absent from both hashes. The required full-preserved-objective audit still has 1499 classes. Neither audit alone is an aggregate-flow decomposition proof; no job aggregation is implemented.
