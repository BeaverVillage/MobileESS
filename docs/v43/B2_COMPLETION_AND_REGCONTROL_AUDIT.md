# B2 종료 및 자동전압조절기 점검

B2는 M1 시간 종료 후 검증된 FULL 가능해를 그대로 인계하여 원본 FCFS Actual과 독립 Fresh를 완료했다. 추가 최적화는 없었다. Actual 실행 PASS, Fresh 물리 FAIL이며 Global Gap 38.079629%는 미인증이다. Fresh 평가 96슬롯 중 30슬롯에서 53건의 노드·슬롯 전압 위반이 있었고, 범위는 0.9461843928~1.0556571528 pu이다. 선로 및 변압기 정격 위반은 0건이다.

사용자의 후속 지시대로 정책·MESS P/Q·경로·RegControl 설정을 변경하지 않고 원래 7 RegControl의 작동을 관측했다. 기존 Actual 물리 원장을 입력으로 한 진단용 AC 재생이며 Actual이나 최적화를 새로 실행하지 않았다. 진단 120슬롯의 전압·위반·수렴·기기 상태는 원래 Fresh 결과와 모두 정확히 일치했다.

7대 모두 전 슬롯 enabled, 감시전압 deadband 이내, 탭 한계 미도달이었다. 제어 명령은 모두 처리됐고 대기 큐는 0, 제어 반복은 최대 5/100회였다. 위 탭 누계는 슬롯별 최종 탭의 순변화로 계산한 하한이며 내부 명령 건수로 주장하지 않는다.

따라서 원래 PR189 snapshot/static 모델에서 조절기 미작동·미완료·포화 결함은 확인되지 않았다. 이 판정은 기존 ControlMode=0에 대한 것이며 Delay/TapDelay의 실제 시간 경과에 따른 TIME 제어 인증을 뜻하지 않는다. 각 조절기는 자기 변압기 권선의 PT/CT 및 R/X 보상 전압을 제어한다. MESS PCC 전체 노드의 0.95~1.05 pu를 직접 감시하는 방식이 아니므로, 제어 deadband 충족과 전 계통 전압 PASS는 별개다.

기존 결과에서 53건은 모두 MESS PCC에서 발생했다. 동결 MESS와 Planning 전력의 선형 모델은 경계 0.95~1.05 이내였으나 Actual 전력으로 바꾸면 선형 모델에서도 36슬롯이 벗어난다. 실제 탭과 예측 계수의 기준 탭은 96슬롯 모두 다르다. 따라서 예측 조건에서 만든 경계 해가 실현 부하·자율 탭 상태에서도 안전하다고 보장되지 않는 것이 확인됐다. 정책을 바꿔 해결했다고 주장하지 않으며 Fresh 물리 FAIL을 보존한다.

PR189의 완료 PASS는 실행·수렴 확인이며 물리 위반은 별도 측정 결과다. PR189에도 이 전압 위반을 자동으로 지우는 P/Q 보정 또는 추가 SVR은 없다.

증거: `V43_B2_FINAL_FCFS_FROZEN_MESS_RESULT.json`, `V43_B2_FRESH_VOLTAGE_CAUSE_AUDIT.json`, `V43_B2_PR189_LINEAR_VS_AC_AUDIT.json`, `V43_B2_REGCONTROL_FUNCTION_AUDIT.json`. 원본 Raw·Native 원장은 수정하지 않았다. 모니터는 기존 http://127.0.0.1:8795/ 에서 실행 완료와 물리 FAIL을 분리 표시한다.
