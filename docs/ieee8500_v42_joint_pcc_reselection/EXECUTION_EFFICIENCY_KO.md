# May01 전용 실행·재사용 기록

연구 날짜는 2025-05-01 96슬롯이다. May02 기록은 SHA로 보존하고 제외했다.

완료96슬롯 11건을 재사용했다. 신규 8건(각96슬롯)과 선택된 PCC의 유한 P/Q 반사실193회를 계산했다. 완료 운전점 Solve는 961회, 명시적 초기화 Solve까지 979회이며 Native/장시간 정책 Solver는0회이다. 기록된 AC 시간 합계는 146.97초다(반사실은 파일 타임스탬프 근사). 중단된 이전 May01 M2 실행의 완료 슬롯 수는0–95 범위 미계측이며 이 완료 집계에서 제외했다. DSS 내부 반복·CalcVoltageBases 내부 해석 수는 계측하지 않았다.

1,783후보×7시간대49,931회 민감도, 원본 모델 감사, 이전46케이스, 적격성·QoS·수학적 증명과 기존 회귀 테스트를 반복하지 않았다. 신규 날짜·재개·계수 가드 테스트6개만 실행해 통과했다. 실제 새PCC의 19개 완료 케이스 저장 배열은 별도 검증했다.

반사실190개와 기준3개는 계산을 마쳤지만 NumPy bool의 JSON 직렬화 오류로 개별 반사실 포트 readback 상세를 저장하지 못했다. 수치 CSV와 실제 포트 제한 검사 요약은 보존했다. AC를 반복하지 않고 파일만 복구했다. 최종96슬롯의 포트 상세 파일은 완전하다.
