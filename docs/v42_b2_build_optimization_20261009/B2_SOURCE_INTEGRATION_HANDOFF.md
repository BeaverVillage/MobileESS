# B2 original constructor input reuse

The source entrypoint is `v42_b2_build_optimization.builder.build_case(payload, request, progress)`. It runs the same SHA-pinned `v42_may_campaign_native90.m_model.build_case` statements. The loader binding changes to a worker-local immutable input port, and phase timers wrap unchanged statement groups. The port caches only the original `v42_bootstrap.m1.native_inputs` result: sites, initial placement, RouteArc objects, Battery parameters, and provenance. Mutable mappings are sealed in canonical JSON and reconstructed for each use. No model, matrix, proof, bound, ledger, incumbent, start, or cross-worker state enters the cache.

The default entrypoint creates its own private port on every call and holds no module-level mutable cache. An officially admitted worker may explicitly own one `VersionedB2BuildPort` instance for repeated same-identity input use. Input caching has no claimed benefit for the first build; the per-build PCS scalar memo provides the first-build repeated-evaluation reduction independently.

Every build creates its original FULL model, Compact formulation and C3A selected formulation. Original transport verification and `verify_case` execute for each new case. Flattening the added timing scopes must reproduce the routed original AST exactly; coefficient constants and scientific statements are not changed. Input preparation, domain/route loading, graph construction, FULL construction, Compact/C3A construction, equivalence verification, and total preparation are measured separately. The real source performance comparison remains `NOT_RUN`.

The first build also removes repeated scalar cos/sin evaluation inside the original `v42_native.mess.pcs_rows`. Each PCS row retains exactly `cos(2*pi*f/FACES)*p + sin(2*pi*f/FACES)*q <= S*cos(pi/FACES)*connected`; its function code object and FACES=16 are unchanged. A private per-build memo uses each original float argument's hex representation and stores the exact first result returned by the original math function. The original module math globals are unchanged. A cloned PCS function is temporarily exposed to the original source solve function for that one admitted model build, then the original function is restored in `finally`. The memo is discarded after each build. This improves a repeated computation present within the first production build; route reuse alone has no first-build speedup claim.
