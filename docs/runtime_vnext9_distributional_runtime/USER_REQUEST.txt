============================================================
0. PRIMARY GOAL
============================================================

Continue JOB-SPECIFIC RUNTIME PREDICTION.

Do NOT replace runtime prediction with aggregate occupancy-only modeling.

The new model must predict a full conditional runtime distribution:

    F_j(t | x_j) = P(T_j <= t | x_j)

from which it must provide:

    Q50_total(j)
    Q90_total(j)

for a newly submitted job, and for an already RUNNING job with observed
elapsed runtime e:

    conditional remaining distribution

        P(R_j > r | T_j > e, x_j)

without retraining a separate model unless later evidence requires it.

Runtime-vNext9 therefore remains a TOTAL RUNTIME predictor.

The goal is to solve the two main Runtime-vNext8 failures:

1. severe long-job undercoverage
2. severe temporal calibration instability

while preserving useful reservation reduction.

============================================================
5. RIGHT CENSORING
============================================================

Unlike simple quantile regression, distributional models should use
right-censored execution observations where scientifically valid.

At a historical cutoff c:

If:

    start_j < c
    and end_j is observed <= c

then:

    exact runtime = end_j - start_j

If:

    start_j < c
    and no end is known by c

then treat as right-censored:

    T_j > c - start_j

Do NOT use the eventual future end timestamp to train that historical fold.

If the job has not started by cutoff:

    it provides no execution-runtime duration information for that fold.

Do not treat PENDING jobs as zero-runtime or censored-from-submit observations.

    RIGHT_CENSORING_AUDIT.json

10. MODEL ARM D1 — DISCRETE-TIME HAZARD BOOSTING
============================================================

Implement a job-specific discrete-time survival/hazard model.

For job j:

    h_j,k =
        P(job terminates in interval k
          | job survived to beginning of interval k, x_j)

Use gradient-boosted trees or another compact tabular learner.

The model must use:

    x_j
    +
    elapsed-age/time-bin representation

but NOT future execution outcomes as inputs.

Construct:

    S_j(t | x_j)

from hazards:

    S_j(t_k) = product_{m<=k} (1 - h_j,m)

Then derive:

    Q50_total
    Q90_total

from the predicted CDF.

Time grid should respect the 15-min control resolution while avoiding an
unnecessarily huge tail model.

Recommended initial grid:

0–4 h:
    15-min intervals

4–24 h:
    1-h intervals

24 h onward:
    coarser intervals justified from TRAIN distribution

Tail endpoint must cover the historical support required for Q90 estimation.

Freeze the binning scheme BEFORE predictive evaluation.

Do not tune bins on April.

33. MOST IMPORTANT SCIENTIFIC PRINCIPLE
============================================================

Runtime-vNext9 is still a JOB-SPECIFIC RUNTIME PREDICTOR.

The change is:

OLD:
    x_j -> one directly regressed Q90 runtime

NEW:
    x_j -> full runtime distribution F_j(t)

which yields:

    total Q50/Q90 before execution

and, after observing elapsed execution:

    conditional remaining Q50/Q90

from the SAME learned distribution.

The goal is to make short-job sharpness,
long-job safety,
and temporal calibration coexist in one coherent model.
