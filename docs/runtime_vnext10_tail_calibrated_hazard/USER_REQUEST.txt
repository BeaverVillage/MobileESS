============================================================
9. REMOVE ADDITIVE TIME-SHIFT CALIBRATION
============================================================

V9 ROLLING14 additive time shift produced zero-support regions and an infinite
proper log score.

Do NOT use additive seconds-shift calibration as the V10 primary approach.

Instead calibrate the predicted probabilities/distribution itself.

Concept:

    raw CDF:
        F_hat(t)

    calibrated:
        F_cal(t) = g(F_hat(t))

where g is monotone.

The SAME monotone mapping must be applied over the whole CDF so that:

    t1 < t2
        =>
    F_cal(t1) <= F_cal(t2)

is always preserved.

Also require:

    0 < F_cal(t) < 1

for finite interior times where the model has nonzero support.

No calibrated distribution may become non-monotonic.
