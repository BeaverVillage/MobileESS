# Branch-and-Price framework

The implementation is opt-in under `v42_bap`; imports do not load scientific input files or start a run. The executable entry point is exclusively `python -m v42_bap.verify`, which constructs bounded synthetic two-slot fixtures. The original 4-MESS/96-slot physical model, A1 freeze, domain, P1/P2, pricing and corrected-bound definitions remain unchanged.

`state.py` owns frozen BinaryProjection/BranchDecision records, immutable local column vectors and append-only provenance, node state, deterministic best-bound queue, validated incumbent and the branch tree. Candidates are ordered by distance to 0.5, then family/MESS/time/site-or-arc (original terms break fully equal keys). No strong branching or lambda-column branching is used. Binary projections must cover every original binary, including charge modes.

The registry keeps all column bytes. Children inherit every parent column satisfying all child decisions; incompatible IDs are node-local inactive entries. Sibling and parent IDs/provenance remain intact. Node-generated columns receive original full-row, exact-integrality, physical SOC/route/travel/PCS16, branch, coupling and reduced-cost validation before admission.

`adapter.py` translates restrictions into equalities on the original local variables in a full-model copy. It reuses existing `Block.price`, `Block.column`, `Block.exact_coupling`, `exact_rc`, `hash_column`, `Master.add`, `global_dual` and the four-unit `corrected`. The one/two-unit bounded theorem is the same sum over its actual blocks; no raw RMP objective is substituted for a dual bound. `native_projections` is a read-only translation of supplied original Blocks and does not construct them.

`solver.py` contains the bounded CG driver. An empty or incompatible inherited pool is repaired by Phase I: artificial slacks on every global row and convexity, while original local domains remain complete. Positive restricted Phase I objective alone is inconclusive. A strictly positive independently corrected full-domain Phase I lower bound or a certified infeasible full original local domain proves node infeasibility. Once original RMP feasibility is established, the true original P1 objective is priced. Every pricing call in the fixtures is compared with the exhaustive compatible-domain optimum at the same node/dual.

Certified node lower bounds monotonically improve; children inherit the parent certificate because their domains are subsets. Global LB is the minimum open-node certified LB. Any unknown open LB prevents a global gap claim. UB is accepted only after a separate validator checks every original physical/scientific row, all original binaries, branch restrictions and the recomputed objective. Gap is `(UB-LB)/max(abs(UB),1e-12)`; the toy acceptance threshold is 0.005. When all leaves close within tolerance, their certified floors are retained, preserving the tiny pricing safety residual instead of overstating exact zero gap.

Supported terminal reasons are NODE_INFEASIBLE, BOUND_DOMINATED, INTEGER_PROJECTED_SOLUTION, PROVEN_NO_IMPROVING_PRICING_AND_INTEGRAL, and EXPLICIT_FIXTURE_TERMINATION. Integer reasons require a validated incumbent and certified node closure; integrality or TIME_LIMIT alone never closes a node. The explicit fixture stop disables global acceptance. The run step limit leaves unresolved nodes open. A valid full-domain bound obtained during TIME_LIMIT can contribute a bound; the status itself is never a proof.

Checkpoint publication writes a unique adjacent temporary file, flushes/fsyncs it, then calls atomic `os.replace`. JSON stores registry bytes/provenance, ordered active queue, completed/internal nodes, branch decisions/tree, bound and terminal certificates, incumbent, counters, global LB, scientific identity, source-content SHA and per-node SHA. Resume verifies payload/node/column hashes, original column rows/semantics, binary branch domain, inherited bounds and pool partition, tree parentage and child completeness, counter/queue partition, global LB, incumbent physical feasibility and objective. Tiny bound certificates are recomputed using the frozen theorem and exhaustive compatible pricing minima. An unfinished temporary write is ignored; a crash inside a node solve replays the still-open node from the preceding atomic boundary.

Resource guard: Threads=1, one Lane-B solver process via a process lock plus thread lock, TimeLimit<=25 seconds (30-second hard postcondition), at most 10,000 vars/20,000 rows, stop on unexpected size/wall excess. Calls are sequential. Locks cover Lane B only and do not interfere with external Lane A. No memory/pagefile benchmark, production import runner, parameter sweep or repository-wide pytest is scheduled.

Fixtures enumerate every legal route/mode pattern and every rational endpoint of each continuous pattern polytope. Continuous lambda mixtures inside a common binary pattern remain allowed; a binary single-vertex choice is not substituted for original trajectory semantics. Each fixture compares direct original MILP, full trajectory master with original binary projections and B&P. A common optimal full physical projection is explicitly imposed and checked in both reference models, so degeneracy does not create a false vector-equality claim.

Production CG completion, branch strategy tuning, exact global original-row incumbent reconstruction and production P2 remain future integration work. This lane makes no production acceptance claim.
