# 원 고객 저압 버스 1,177개 AC 민감도 — V3 시뮬레이션 설계

원 IEEE8500 고객 저압 버스 **1,177개 전부**에서 P/Q 중앙차분을 실제 OpenDSS AC로 계산했다. 2025-05-01의 이미 노출된 개발 시점 0, 9, 48, 75를 고정하고, 각 버스에 ±0.1 kW 또는 ±0.1 kvar를 각각 적용했다. 기본 교란 AC 18,832회와 첫 사전 정렬 버스의 반 간격 검증 16회, 합계 **18,848개 교란 상태가 모두 수렴**했다. Native 호출과 전체 최적화 모형 구축은 0회다.

이번 결과의 지위는 **SIMULATION_DESIGN_NOT_FIELD**다. 사용자 승인에 따른 설계 가정으로 기존 고객 변압기와 Triplex를 사용하며, 새 고객 변압기를 추가하지 않는다. 설치 현장 증명이 없다는 이유로 설계 후보를 배제하지 않았다. 보호협조·중성선 독립 정격·역송전 허용 조건·차량 접근과 접속 시간은 별도 설계 조건이며, 원 자료에 없는 승인을 만들어 내지 않았다.

## 계산 전에 고정한 기준

- `PREREGISTRATION.json`에 1,177개 버스와 LVv3 식별자, 4개 시점, 원 정격과 소스 SHA, ±0.1 교란, 20개 선로와 대조 기준을 고정했다.
- 원 고객 부하의 P/Q에 정적 배경 비율 **0.552**를 적용했다. AIDC는 과거 v3 호스트의 현행 V42 REFERENCE 원 스케일 1.0이며, 수요는 복사된 `PLANNING_PHYSICAL.npz`의 P/Q를 그대로 사용했다. 작업·REFERENCE를 재구성하거나 B1/B2/B3 결과를 점수에 사용하지 않았다.
- 기본 MESS 전력은 0이다. 1상 240 V 단일 상수전력 delta 소자를 원 120/240 V 활선 노드 1/2 사이에 연결했다. 두 독립 120 V 전력을 합산하는 모델을 사용하지 않는다.
- 원 소스 1.05 pu, 원 조정기 Vreg, 커패시터와 CapControl, 선로 및 변압기 정격을 유지했다. 각 시점은 원 초기 탭/커패시터에서 독립적으로 자동 제어를 정착시켰다. 그 시점의 모든 교란은 같은 정착 상태를 복원한 뒤 제어를 껐다. 탭/커패시터 동일성, 정착, 제어 큐 비움, 실제 P/Q 응답을 매 교란에서 확인했다.
- 20개 대상 선로는 v2의 사전 고정 목록을 복사했다. 새 민감도로 선로를 다시 선정하지 않았다. 각 선로의 해당 시점 기준 상태에서 최대인 원 소스 방향 단자·활선 위상을 고정해 dI/dP, dI/dQ, dρ/dP, dρ/dQ를 계산했다. 모든 단자 최대치는 보수적 열감사로 별도로 남긴다.

네 기준 모두 원 전압 상한 1.05 pu를 넘으므로 최종 적격 B0가 아니다. 이 전역 실패를 기록하되, 관련 없는 소스 인근 과전압을 이유로 1,177개 포트를 일괄 배제하지 않는다. 모든 작은 교란에서 기준에 없던 새 선로·변압기 과부하와 새 전압 위반은 0이었다. 기존 전압 실패가 해소되었다는 뜻은 아니다. `PCC_ENDPOINT_SUMMARY_SLOT_*.csv`에는 기존/새 위반 수, 최악 축, 전역 극값과 국부 CT/Triplex/PCC 값을 각각 남겼다.

## 국부 값과 독립 확인

각 후보의 기존 CT 전 권선 전류, 원 정상 정격 전류 대비 비율, 복소 kVA와 **nameplate kVA** 대비 비율을 저장했다. 각 Triplex 경로의 양 단자·두 활선 전류와 추정 중성선 전류, PCC 두 노드 전압, 실제 PCC P/Q와 복소 활선 전류를 저장했다. 원 Triplex 중성선은 Kron 축약되어 별도의 독립 허용 전류가 없으므로 중성선 암페어를 측정해도 그 정격 통과를 선언할 수 없다.

독립 저장 결과 확인에서 실제 P/Q 최대 절대 오차는 **9.167e-11 kW/kvar**, PCC 두 활선 복소 전류 합은 **0 A**, 원 NormalAmps와 dI/dρ의 일치 오차는 **2.132e-13 A/단위**였다. 각 시점의 사전 정렬 첫 후보에서 ±0.05 반 간격 검증을 수행했고 최대 dI 차이는 0.003350 A/단위 미만으로 코드에 고정한 0.01 기준을 통과했다. 이 검증은 전체 후보의 유한 전력 운전 선형성을 증명하지 않는다.

`BASELINE_READBACK_PREREGISTRATION.json`을 별도로 고정한 뒤 기준 AC 4회를 추가 재현했다. 원 정착 제어 상태가 모두 같고, 기준 전역 극값 오차가 1e-10 이하인 상태에서 `BASE_LOCAL.npz`에 정확한 국부 기준 값, PCC 실제 선간 전압, 원 CT 명판 코일 전류와 권선 kVA를 보존했다. 기준 AC 총 8회와 교란 AC 18,848회를 구분해 기록한다.

원 SourceBus 연결에는 `Reactor.HVMV_Sub_HSB`가 필요하다. 과거 공통 경로 함수에서 inventory의 누락된 reactor 목록을 가정하면 교차 필드가 잘못 비어질 수 있다. 이번 모듈은 실제 원 reactor를 직접 읽어 모든 고객의 소스 경로 포함을 확인했다. 20개 선로와 해당 경로의 교집합을 NPZ에 기록했다.

## 점수의 의미와 다음 운전 검증

설계 하드웨어 가정은 Schneider XW Pro 6848 NA, |P|≤5 kW, |Q|≤3 kvar, S≤6 kVA, 활선 27 A다. `CANDIDATE_SCORES.csv`는 **원 국부 CT/Triplex와 PCC .95–1.05 전압의 1차 제약** 및 가정 전력 한도를 교차시켜 작은 교란의 선로 ρ 응답에 곱한 상한 잠재력이다. 전압에 따른 활선 S 상한의 점수 계산은 기준 두 노드 중 작은 크기의 두 배를 사용하는 1차 근사이며, 정확한 선간 전압은 `BASE_LOCAL.npz`에 별도로 있다. 실제 유한 전력에서의 전압·전류 제한과 역송전·보호 자격을 대신하지 않는다.

첫 세 후보의 이 진단 점수는 sx2802480b 0.106077, sx3141411c 0.090442, sx3645811c 0.088180이다. 점수는 네 개발 시점·20개 선로 중 최대 1차 응답이며, 최종 B3 성능 개선이나 동시 포트 동작의 예측치가 아니다. 고객 좌표는 upstream primary proxy와 원 unknown CRS를 사용하고 실제 고객/주차 지리 위치의 정확성을 주장하지 않는다.

선정된 설계에는 96개 시점의 실제 +/−5 kW 충방전, +/−3 kvar, P/Q 조합 |P|=5·|Q|=3 검증과 두 활선 27 A, S≤6 kVA, 원 CT/Triplex/전압·전역 새 병목 검증이 별도로 필요하다. 이번 실행은 그 전체 운전 자격을 수행하지 않았으며 `actual_full_rating_qualified=False`와 `production_certificate=False`를 유지한다.

## 산출물과 재현

모든 후보의 전 수치는 `LV_SLOT_00/09/48/75.npz`와 `AXES.json`에 있다. NPZ 순서는 후보, P/Q, 음/양 주입, 장비 축이며, 가변 경로의 끝은 NaN 패딩이다. 전체 1,177개 점수와 20개 상위 후보는 작은 CSV로 제공한다. 선로별 전체 후보 극값은 `TOP20_LINE_AGGREGATE.csv`에, 상위 20 후보의 상세는 `TOP20_CANDIDATE_RESPONSES.csv`에 있다. 원 전체 선로 응답 CSV를 작은 뷰로 압축한 이력·SHA·전체 NPZ 대체 위치는 `BASELINE_READBACK_RECEIPT.json`에 기록했다.

```powershell
python -B -m ieee8500_v42.lv_reproduce --output ieee8500_v42/outputs/lv_v3_reproduction_01
python -B -m unittest tests.test_ieee8500_v42_lv_sensitivity -v
```

재현 래퍼는 새 폴더나 빈 폴더만 허용한다. 기존 결과·SHA 영수증을 덮어쓰지 않고 동일 사전 정의로 모든 AC/국부 기준 읽기/독립 검증을 실행한다. 모듈 소스, 각 입력 SHA, 실제 실행·검증과 산출물 SHA는 `PREREGISTRATION.json`, `RECEIPT.json`, `BASELINE_READBACK_RECEIPT.json`, `INDEPENDENT_NUMERICAL_VERIFICATION.json`에 보존했다. 6개 경량 테스트는 원 reactor 경로, 과부하 복구 최소 전력, 상충 국부 제약, 기존/새 위반 분리와 1,177개 사전 등록을 확인한다.
