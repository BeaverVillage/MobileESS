# Sources and interpretation boundary

- [NLR Kestrel dataset](https://data.nlr.gov/submissions/302): job-level Slurm accounting fields and the raw archive/datacard. Collection uses sacct with a mutable database and derived updates. This describes the released extract; it does not certify historical request versions or a complete as-of population.
- [XGBoost AFT documentation](https://xgboost.readthedocs.io/en/stable/tutorials/aft_survival_analysis.html): exact labels use equal lower/upper bounds, right-censored labels use a finite lower bound and infinite upper bound, and log lifetime is tree margin plus a specified location-scale noise distribution. This study fixes normal noise and sigma=1.0, making the conditional remaining quantile `exp(margin + normal_ppf(tau))`.
- Runtime/code baseline: PR65 and PR68 frozen evidence. `07_hpc-oda-commons` supplies model/preprocessing implementation authority only; it is never treated as a scheduler snapshot.

The initial audit found insufficient authority for a certified historical censoring population (`CENSORING_AUTHORITY.json`). The user's subsequent explicit instruction permits V40S4 `D1_SCHEDULER_REQUEST_STATE_PROXY_V1` and an **archive-conditional as-of risk-set proxy**, while preserving UNVERIFIED/UNOBSERVED provenance. `PROXY_AUTHORIZATION.json` records that scope change and links the earlier audit rather than deleting it.

All raw GPU records were scanned before the as-of filter, including any null-end records if present. The actual released GPU extract contains zero null-end rows and only terminal states. We do not invent never-completed rows or infer that the true historical population had none. At an earlier issue, archive rows without an observed prior completion are administratively right-censored; only the Boolean occurrence of end<issue is used, then any future end value is discarded. This does not establish unbiased population survival or remove archive inclusion/retention bias. Production readiness remains fail-closed.
