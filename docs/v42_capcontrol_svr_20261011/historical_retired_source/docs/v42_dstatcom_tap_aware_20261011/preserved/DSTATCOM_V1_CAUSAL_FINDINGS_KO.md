# V1 D-STATCOM 전압 악화 원인 감사 — 개발 단계, 캠페인 보류

원래 7개 RegControl을 유지한 96슬롯 Fresh AC에서 V1 순수 로컬 PCC 제어는 전체 계통의 전압 안전성을 통과하지 못했다. 원본 계획과 Actual 외생 입력은 그대로 보존되었다. 이 문서는 정격·Gain 수정이나 새 최적화 실행을 제안하는 설계 승인서가 아니라, 보존된 실패 결과와 완료한 인과 진단의 범위를 기록한다.

| 실제 96슬롯 조건 | 장치 수 | 과전압 셀 | 저전압 셀 | 기존 19셀 해소 | 새 위반 셀 | 원본 선로 전류 위반 셀 | 원본 변압기 전류 위반 셀 | 원본 변압기 kVA 사건 | 전체 물리 PASS |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|
| 원본 OFF | 0 | 19 | 0 | 0 | 0 | 0 | 0 | 0 | FAIL |
| STA08 단독 V1 ON | 1 | 40 | 0 | 7 | 28 | 0 | 0 | 0 | FAIL |
| 기존 V1 전체 ON | 36 | 921 | 0 | 19 | 921 | 456 | 24 | 8 | FAIL |

전압의 셀 단위는 **노드×상×슬롯**이다. 전류 셀은 원본 Fresh NPZ의 **가지×상×슬롯**이다. 변압기 kVA는 `reg1a`의 동일한 전체 kVA 값을 3개 상 열에 반복 기록하므로, 24개 원시 상 행은 **8개 변압기 요소×슬롯 사건**으로 따로 집계했다. OFF도 19개 전압 위반이 있으므로 전체 물리 PASS가 아니다.

V1 36대는 24개 논리 장소의 **36개 서로 다른 PCC**였다. 충전소 MESS PCC 12대, IDC 부하 AIDC PCC 12대, 별도 IDC MESS PCC 12대이다. 동일 PCC에 장치를 중복 생성한 경우는 0이다. 최신 최종 시나리오가 요구한 설치 대상은 앞의 24대이며, 별도 IDC MESS 12대는 원래 계통의 모든 노드 검사에 포함된다. 이전 36대 실패를 24대 결과로 재명명하지 않는다. 기존 V1 총 명목 정격은 27.75 MVAr이고, 최신 24대의 18.75 MVAr는 아직 최종 승인된 설계가 아니다.

## 실제 악화 위치와 탭/Q 흐름

전체 V1의 921셀은 모두 원래 피더의 원격 노드이다. 기존 MESS/IDC PCC에서는 전압 위반이 0이며, 원격 32개 노드·상에서 B상 645셀, C상 160셀, A상 116셀이 발생했다. 모든 셀을 원래 OFF 전압, Actual Q 합계, 7개 탭, 선로 전류 및 변압기 kVA와 연결한 CSV를 보존했다.

최악은 슬롯 55의 `150r.C`이다. OFF 1.0312323249544848 pu에서 ON 1.068705974965709 pu로 상승했다. 같은 시점 피더 입구 `reg1a` 탭은 1.0312500000000002에서 1.0687500000000005로 **0.0375 상승**했다. Source `150.C` 전압은 0.9999872948235553에서 0.999969428641648 pu로 **0.000017866 감소**했다. Source 자체의 전압 상승으로 설명되는 결과가 아니다. 이 측정은 Q 흐름에 따른 원래 레귤레이터의 탭 응답과 원격 전압 악화가 함께 발생했다는 증거다.

V1의 실제 총 Q는 하루 내내 흡수 방향이며 −1.010061~−3.307906 MVAr이다. `reg1a`는 OFF 대비 96슬롯 모두 상승했고, `reg4b` 역시 96슬롯 모두 상승했다. `reg4b`의 OFF 대비 탭 차이는 +0.03125~+0.08125이다. 원래 DSS 상별 연결 그래프에서 가장 가까운 레귤레이터 2차측을 연결하면 921셀 중 `reg4b` 인근 525셀, `reg1a` 인근 384셀, `reg4a` 인근 8셀, `reg4c` 인근 4셀이다. 이 분류는 전기적 연결 간선 수에 따른 근접성으로, 단일 레귤레이터의 독점적 인과 책임을 뜻하지 않는다.

STA08 단독의 96슬롯도 전체 전압 안전성을 통과하지 못했다. 처리된 STA08 PCC의 전압 위반은 없지만, 원래 19셀 중 12셀이 남았고 다른 28셀이 새로 발생했다. 최악은 슬롯 13의 처리되지 않은 `STA06.B`이며 OFF 1.055356519156493에서 ON 1.0682074664675818 pu로 상승했다. 이 결과는 장치 개수가 많을 때만 생기는 현상으로 한정할 수 없음을 보여준다.

## 부호·단위·정격·중복 계상 검증

108개 Generator와 108개 양의 손실 Load, 108개 전용 단상 연계 Transformer, 108개 전용 Lead 이름은 각각 유일하다. 기존 MESS/AIDC 주입 요소 이름과 충돌하지 않았고, 기존 MESS/AIDC 명목 P/Q는 모든 96슬롯에서 보존됐다. D-STATCOM과 MESS PCS의 용량을 공유한 기록은 없다.

36대×3상×96슬롯의 10,368개 실제 장치 행에서 API 명목 kvar와 지령의 최대 차이는 2.842170943040401e−14 kvar, 실제 Q와 지령의 최대 차이는 2.6815585272288445e−6 kvar였다. Actual 공급 Q는 캡처한 V1 `device.measure`의 **Generator 단자 Power 허수부의 음수**로 계산된다. Generator P 명목값은 0이고, 변환기 손실은 별도 양의 P Load로 처리된다. 실제 PCC 전압 readback은 원본 Fresh NPZ와 오차 0이었다. 새 전용 설비와 기존 서비스 변압기의 상별·권선별 검사는 통과했다.

실제 사용점이 명목 정격 안에 있다는 사실과 1.5배 설계 여유는 별개다. 전체 V1에서는 IDC01_AIDC의 상별·전체 변환기 1.5배 여유가 명목 정격에도 부족했고, 운전 가능 kVA 90%를 기준으로 하면 STA06_MESS의 B상에도 1.5배 여유가 부족했다. 이 기록은 해당 제어가 실제 사용한 apparent power와 손실을 기준으로 한다. 전압을 고치기 위한 최소 필요 Q나 미래의 모든 배치에 대한 강건 설계 증명이 아니다.

## 완료한 단일·단계 진단의 범위

실제 STA08 물리 연계 뱅크의 ±25/±100 kvar 상별 부호·단위·손실·전류 검사가 통과했다. 고정 탭의 A상 −25 kvar는 자기 상 전압을 낮추면서 다른 상 전압을 조금 올렸다. 상간 결합을 무시한 독립 상 보정으로 해석할 수 없다. 큰 ±100 kvar 자동 제어 시험에서는 원래 레귤레이터의 탭도 변했다.

당시 명시적으로 허용된 슬롯 10 단계 진단은 원래 OFF 슬롯 0~10을 정확히 재현한 뒤, 매 조건별 독립 컨텍스트에서 V1 정격·제어 파라미터를 유지해 실행했다.

| 장치 구성 | 원래 정착 탭 고정: 총 Q(kvar) | 자동 7개 RegControl: 총 Q(kvar) | 고정/자동의 전체 노드·전류·변압기 위반 |
|---|---:|---:|---|
| STA08, STA06 | −279.073 | −353.861 | 모두 0 |
| 위 2대 + STA01, STA12 | −250.329 | −323.666 | 모두 0 |
| 최종 대상 충전소12 + IDC 부하12 | −242.745 | −566.817 | 모두 0 |

모든 단계의 현재 슬롯 피드백은 수렴했다. 그러나 이 결과는 96슬롯 상태 이력을 재현한 결과가 아니므로 하루 또는 캠페인 승인으로 확대하지 않는다. 과거 36대 ON의 슬롯 10은 이전 ON 슬롯들의 Q·탭을 이어받았으므로 위 즉시 24대 진단과 장치 수만의 효과를 순수하게 비교할 수 없다.

이전 고정 탭 진단은 원본 제어가 정착한 후 진단 전용 컨텍스트에서만 수행됐으며, 수동 탭 setter를 사용하지 않았다. 최신 지시 이후에는 새로운 고정/비활성 RegControl 시험을 실행하지 않는다. 이후 모든 물리 실행은 원래 7개 자동 제어를 유지한다.

## 응답 예측 검증과 남은 원인 식별

기존 슬롯 10의 ±1 kvar 상별 전 계통 민감도와 실제 물리 뱅크 Q를 이용한 응답 예측을 검증했다. Q=0 물리 뱅크 기준 전압에서 계산한 최대 오차는 고정 탭 2/4/24대의 경우 약 0.00105~0.00109 pu였다. 자동 탭에서는 2/4대 약 0.0133 pu, 24대 약 0.03253 pu였다. 큰 Q의 비선형 응답, 실제 연계 뱅크 손실 및 탭 변화는 이 작은 Q 고정 탭 행렬에 모두 표현되지 않는다. 따라서 오차를 레귤레이터 하나의 고장으로 단정하지 않는다.

보존된 V1 로그에는 실제 보상 Sensor 전압과 복소 권선 전압·전류의 독립 readback이 없다. 이 값은 **UNKNOWN**으로 유지한다. Source의 Vreg/ptratio/R/X 파라미터를 실제 Sensor 측정값으로 바꾸어 기록하지 않는다. 다음 진단은 현재 슬롯의 실제 원격 노드 전압·탭·복소 권선 전압/전류·LDC 보상 Sensor를 측정하고, 원래 자동 제어를 유지한 작은 물리 Q 변화의 예측과 실측을 비교해야 한다. 정격이나 Gain을 먼저 변경해 실패를 가리지 않는다.

관측된 실패 유형은 **로컬 PCC 전압은 제어되지만 Q 흐름과 기존 자동 탭의 상호작용으로 원격 전압 및 계통 전류가 악화되는 현상**이다. Q 부호·단위·기존 MESS의 이중 계상 결함은 현재 저장된 검증에서 발견되지 않았다. 어떤 장치·센서·배치가 필요한 탭 응답을 유발하는지에 대한 유일한 원인과 안전한 교정 법칙은 아직 확정되지 않았다. 전체 캠페인은 보류 상태다.
