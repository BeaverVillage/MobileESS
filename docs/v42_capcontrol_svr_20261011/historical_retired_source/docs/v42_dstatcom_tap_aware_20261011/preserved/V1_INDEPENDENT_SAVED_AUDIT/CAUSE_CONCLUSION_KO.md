# V1 실제 저장 결과의 원인 진단

현재 V1 후보는 전체 물리 검증에 실패했다. 31일 캠페인 승인 근거로 사용할 수 없다. 이 문서는 이미 저장된 OFF/ON 결과와 별도로 승인된 STA08 단일 장치 부호·단위 진단을 구분한다. 추가 Native 최적화, 용량 변경, Gain 실험은 수행하지 않았다.

## 관측된 원인과 배제한 구현 오류

저장된 36개 장치의 10,368개 상·슬롯 읽기값에서 Q 지령과 실제 Q의 최대 차이는 0.000002682 kVAr였다. 양의 Q는 공급, 음의 Q는 흡수로 동작했다. I × 실제 상전압과 실제 상별 피상전력의 최대 차이는 1.14×10^-13 kVA였다. 전체 정격은 장치별 750/1500 kVA이며 각 상 정격은 그 값의 1/3이다. 36개 장치 ID, 36개 PCC, 432개 추가 전기소자 이름은 모두 고유했다. 같은 버스에 중복 장치를 설치하거나 3상 총량을 각 상에 다시 적용한 증거는 없다. 각 장치 PCC 측정값은 기존 raw 노드·상 좌표의 전압과 정확히 같았다.

STA08 실제 절연·연계 변압기를 포함한 단일 장치에서, 원래 슬롯 0~10의 전압·탭을 정확히 재현한 뒤 각 상에 ±25/±100 kVAr를 적용했다. 24개 진단 모두 부호·단위·접속·전류·손실 검증을 통과했다. A상 −25 kVAr는 zero-Q 장치 기준 A상 전압을 1.058072→1.049632 pu로 낮췄다. 동시에 B상은 1.055290→1.055502, C상은 1.054876→1.055926 pu로 상승했다. ±100 kVAr에서는 원래 자동 RegControl의 탭 응답이 나타났다. 의도적 Q 시험 중 남은 전압 위반은 숨기지 않았으며 이 시험을 전체 네트워크 PASS로 표시하지 않았다.

이는 현재 증거에서 부호·kvar 단위·상 좌표·3상 총량·장치 중복 구현 오류를 발견하지 않았다는 뜻이다. 다른 모든 소프트웨어 오류의 부재를 증명한 것은 아니다.

## 전체 계통의 제어 설계 실패

V1 전체 ON에서 원래 19개 위반 좌표는 해결됐으며 모든 MESS/AIDC PCC의 최종 전압은 허용 범위였다. 그러나 다른 원래 계통 노드에서 921개 전압 위반이 발생했다. 최악은 슬롯 55의 150r.C로, OFF 1.031232→ON 1.068706 pu였다. 원래 선로의 전류 위반은 456개 상·슬롯이며 최대 부하율은 130.188%였다. 추가 장치와 직접 연결된 기존 서비스 변압기들의 양쪽 권선은 최종 장치 감사에서 통과했지만, 다른 원래 계통 변압기 한계는 전체 네트워크 감사에서 실패했다.

장치의 총 Q 흡수는 슬롯별 1.010~3.308 MVAr였다. 예를 들어 슬롯 49에서는 총 3.066 MVAr를 흡수했고 Reg6 탭은 OFF 1.04375에서 ON 1.1로 올라갔다. 같은 슬롯의 최대 원래 선로 부하율은 OFF 54.704→ON 130.188%였다. V1은 건강한 PCC 전압까지 1.025 pu 근처로 낮추려 했으며, 다수 장치의 Q 흐름과 기존 조정기의 응답이 함께 변했다. 실제 단일 장치에서 상간 역방향 효과도 확인됐다. 이 사실들은 광범위한 Q 순환·상간 결합·자율 탭 응답의 설계 문제를 뒷받침한다. 탭 효과와 비선형·상간 효과의 정량적 기여를 유일하게 분리하려면 고정/자동 탭의 단계별 비교가 더 필요하다.

9개 슬롯은 전기적 수렴과 별개로 300회 로컬 피드백 내 제어 수렴 조건을 완성하지 못했다. 이 실패는 보존돼 있다. 이를 수치 허용오차를 늘려 PASS로 바꾸지 않는다.

## 위치와 용량

V1은 24개 논리 사이트의 36개 서로 다른 물리 끝점에 27.75 MVAr를 설치한 개발 후보였다. 최신 요청은 12개 STA MESS PCC와 12개 IDC AIDC PCC, 정확히 24개 및 초기 18.75 MVAr이다. 추가 IDC MESS 12개는 서로 다른 버스에 놓인 장치였으므로 중복 계상 오류와는 구분해야 한다. 최신 설치 범위는 새 계약으로 명확히 검증해야 한다. 설치하지 않는 IDC MESS 노드들도 전체 네트워크 검사에서 통과해야 한다.

V1의 실제 관측 피상전력 기준으로 IDC01_AIDC의 상별·전체 1.5배 여유는 실패했다. 최소 명판 여유는 1.179배, 90% 사용 가능 용량 기준으로는 1.061배였다. STA06_MESS B상은 명판 여유 1.610배지만 사용 가능 용량 여유 1.449배였다. 이는 현재 제어로 관측된 여유 부족이며, 원인 진단 전에 설비를 늘릴 근거가 아니다. 정격에 비례해 Q 목표를 늘리는 설계에서는 증설이 순환을 악화할 수도 있다.

## 다음 제어 아키텍처 검토 조건

아직 새로운 Gain·용량을 승인하거나 시험하지 않았다. 이후 공통 설계의 후보는 다음 구조로 검토할 수 있다.

1. 허용 범위 안의 건강한 PCC를 일괄적으로 낮추려 하지 않는 보호 중심 로컬 동작 영역과 명시적인 상별 히스테리시스.
2. 변환기 명판 용량과 독립적인, 사전 설계·동결된 상별/전체 운전 Q 한도. 지역별 합계 Q의 최악 범위를 제한하는 고정 배분은 오프라인 개발 계통 응답을 근거로 검증한다.
3. 현재 로컬 상별 전압과 장치/연계 전류로 제한한 변화율, 제한 후 실제 Q만 추적하는 상태, 적분 누적을 남기지 않는 anti-windup. 다른 상을 악화시키는 명령의 보류/축소 여부도 실제 상간 응답으로 검증한다.
4. 원래 RegControl 설정을 유지하고, 관측된 전압 변화·탭 응답과 Q 피드백의 순서를 검증한다. 기존 snapshot/static SolveSnap이 제어 큐를 정리하는 방식과 가정한 변환기 피드백 초 수를 구분해야 한다. 현재 반복 횟수만으로 실제 시간 영역 협조를 증명하지 않는다.
5. 단일→2개→4개→요청된 전체 24개, 고정 탭 진단→원래 자동 탭 비교, 이후 정확한 96슬롯 및 과거 예측오차·MESS 이동 조건의 개발 검증을 통과한 하나의 계약을 동결한다.

순수 로컬 PCC 전압은 원격 노드의 전압과 공용 상위 선로 전류를 직접 관측하지 않는다. 서로 다른 원격 상태가 같은 로컬 전압을 만들 수 있으므로, 이 입력만 사용하는 유한 장치로 모든 계통 상태에서 모든 노드의 전압과 열 한계를 무조건 보장할 수 있다고 주장할 수 없다. 오프라인 설계 범위와 실제 실행에서 검증한 결과를 보고해야 한다. 추가 관측이나 계통 협조 계약이 필요한 경우 사용자 범위와 별도로 명시해야 하며, Actual 최적화나 미래 입력 사용으로 대체하면 안 된다.
