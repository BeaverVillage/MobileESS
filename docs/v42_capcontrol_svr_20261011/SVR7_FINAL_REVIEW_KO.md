# SVR4 / SVR7 공통 인프라 AC-only Canary 결과

**두 구성 모두 B2 May03에서 새 과전압 2건이 발생해 대표 날짜 게이트에 실패했다. 월간 확대와 새 31일 Gurobi 캠페인을 중단·보류한다. 승인된 최종 공통 설비는 없다.** SVR7은 이번 5개 정책·날짜 쌍의 최악 Vmax와 최대선로부하율이 더 낮은 후속 검토 후보로만 선정한다. 이 선택은 전압 위반 0건 또는 월간 안전성 승인을 뜻하지 않는다.

실행 Source SHA: `ce30af2a74d9d2b6a2f2a33fee7a690927752f940f94bd466218075ba34cbf04` (1,225개 실행 파일). 평가 전 SVR4 `.06`, SVR7 `.02`를 동결했으며 평가 중 위치·정격·제어 설정·원본 장치·전압 한계를 변경하지 않았다.

## 1. 정확한 설비 구현과 후보 선정

기존 STA01/STA06/STA08/BUS83 네 장치의 계약 DTO, 물리 구현 바이트와 초기 상태를 그대로 유지했다. SVR7은 실제 `78→79 Line.l79`, `105→108 Line.l105`, `49→50 Line.l49`의 하류 terminal 2에 직렬 설비를 추가한다. 존재하는 선로의 임피던스·길이·상·전류 정격을 보존하고 기존 하류 버스를 그대로 유지했다. `47→48 Line.l47` 대안은 설치하지 않았다.

BUS50은 IDC04 및 IDC02의 네 물리 LV 접속점을 직접 포함하는 실제 분기이고 BUS48은 IDC06의 두 물리 LV 접속점을 포함한다. 사전 알려진 May01/May28에서 두 대안을 실제 96슬롯으로 비교했으며 모두 물리 PASS였다. BUS50은 그 두 대안 중 약간 낮은 선로부하율·손실과 넓은 접속점 범위를 보였으나 모든 날짜에 대한 최적 설치점이라고 주장하지 않는다. 후보 선택용 Source2cf 시험과 최종 Sourcece30 시험은 분리했다. 개발에 사용한 날짜는 독립 Holdout이 아니다.

총 7개 은행은 21개 단상 변압기와 21개 추가 RegControl이다. 기존 네 은행은 합계 5,132.132544 kVA, 일곱 은행은 13,778.530175 kVA다. STA 장치는 각 250kVA/상, 추가 MV 은행과 BUS83은 각 960.710848kVA/상·400A다. 모든 SVR은 유한 정격, Tap 0.9–1.1, 32단계, 단계폭 0.00625, VReg=120V, Band=2V, Delay=30초, TapDelay=2초 및 MaxTapChange=1을 사용한다. 실제 winding, 연결, 감지 버스, PT/CT, 손실 가정은 `SVR7_PHYSICAL_RATING_AUDIT.csv`에 명시했다. 강제 이상 전압원을 추가하지 않았다.

원본 IEEE123 RegControl 7개는 정적 설정·정격·VReg/Band/LDC·탭 범위·Delay=15초·TapDelay=2초를 유지한 AUTO다. 원본 커패시터 C83 600kvar와 C88a/C90b/C92c 각50kvar는 Fixed-ON이다. 평가의 CapControl 및 D-STATCOM 개수는 0이다. Tap과 추가 전압제어는 MILP 결정변수가 아니다. 투자비·설치비 및 경제성은 연구 범위 밖이며 수행하지 않았다.

신규 세 은행의 다섯 Actual 날짜 4,320개 상·슬롯에서 terminal 2의 유효전력 `P_into>0` 역방향 사례는0이었다. 실제 관측은 정방향이며 양방향 실운전 검증 완료로 표시하지 않는다. 전력·무효전력 부호를 구분한 양단 P/Q와 물리 모델의 유한 연결은 별도 감사에 보존했다.

## 2. 같은 동결 계획의 직접 물리 비교

각 날짜의 기존 AIDC/MESS P/Q·이동경로·SOC와 Actual 외생 입력을 그대로 사용했다. 과거 STATIC REF 저장 배열은 B1/B2 13개, B0 15개 모두 bit-exact로 재현한 뒤 SVR 재생을 승인했다. 아래 REF는 세 구성과 동일한 native TIME 제어로 실행한 REF_TIME이다. STATIC 기준에서는 May02 104개·May03 172개였고 TIME 기준은 각각106개·168개로 다르므로 두 기준을 섞지 않는다.

|---|---:|---:|---:|---|
| B2 May01 | 19 / 1.058375488 | 0 / 1.046164354 | 0 / 1.046527034 | PASS / PASS |
| B1 May28 | 2 / 1.050228286 | 0 / 1.047368732 | 0 / 1.047583158 | PASS / PASS |

| B2 May03 | 168 / 1.063792848 | 2 / 1.050473390 | 2 / 1.050141371 | FAIL / FAIL |
| B0 May01 | 0 / 1.048495347 | 0 / 1.047538003 | 0 / 1.047230306 | PASS / PASS |

위반은 전체 원본·추가 노드 및 상의 슬롯별 셀 수다. REF_TIME/SVR4/SVR7은 각각386/398/407개 노드·상이다. 15개 주요 TIME 궤적 모두 96슬롯을 순서대로 실행했다. 각 시나리오 10개 시험에는 STATIC 원본 재현 게이트도 포함해 총25개 독립 Fresh 컨텍스트를 사용했다. 각 구성에서 4개 PASS, 1개 물리 FAIL이며 테스트 코드 PASS와 구분한다.

전체 선로 양단·상 전류, 원본·추가 변압기 양단 전류/native NormalAmps·명판 전류·winding kVA 및 SVR 자체 정격 위반은 모든 15개 궤적에서 0이다. 최대 양단 선로부하율은 SVR4 73.022929%, SVR7 72.831625%다. 원본 Raw terminal-1 축의 최대값은 각각73.022879%,72.831574%이며 별도 열로 보존했다. 모든 시나리오 96슬롯은 해석 수렴 및 현재 시각까지 도래한 제어 완료를 만족했다.

최악 전압 여유는 SVR4 상한 −0.000473390pu / 하한 +0.010003918pu, SVR7 상한 −0.000141371pu / 하한 +0.010080209pu다. SVR7이 May01/May28의 최대 전압은 오히려 조금 높인다. May02 SVR4의 상한 여유는 +0.000123918pu로 작다. 따라서 SVR7이 항상 더 안전하다는 일반화는 하지 않는다.

## 3. May03의 새로운 상류 과전압

REF_TIME의 원래168개 위반 셀은 두 구성에서 모두 해소됐다. 그러나 원래 허용범위 안이었던 Bus82의 다른 셀에 새 위반이 두 개씩 생겼다. 모든 결과를 보존하며 이를 성공으로 처리하지 않는다.

| 구성 | 슬롯 0 / 1 기준 | AEST 시각 | 노드·상 | 전압 pu | 최대 상한 초과 pu |
|---|---|---|---|---:|---:|
| SVR4 | 37 / 38 | 09:30 | 82 B | 1.050382051 | 0.000382051 |
| SVR4 | 87 / 88 | 22:00 | 82 A | 1.050473390 | 0.000473390 |
| SVR7 | 37 / 38 | 09:30 | 82 B | 1.050080874 | 0.000080874 |
| SVR7 | 86 / 87 | 21:45 | 82 A | 1.050141371 | 0.000141371 |

09:30의 REF_TIME 82.B는1.046388353pu였으며, SVR4/7은 각각 +0.003993698/+0.003692521pu 높아졌다. 같은 시각 SVR4의 BUS83 B상 탭은0.95이고 감지83.B는1.001705720pu, 추가 regulated MV.B는1.000306792pu다. 탭 하한0.9에 막힌 상태나 제어 미수렴으로 설명되지 않는다.

실제 상별 조상 경로에서 Bus82는 BUS83 은행과 `Line.l84`보다 상류에 있다. BUS83의 감지83 버스를 정상으로 유지하는 제어는 Bus82를 직접 감지·직렬 보상하지 않는다. 신규 BUS79/108도 Reg4 아래의 서로 다른 형제 분기여서 Bus82의 직접 제어 대상이 아니다. Reg4와 추가 SVR의 간접 전력 흐름·전압 상호작용은 남는다. 같은 입력에서 네 장치 개입이 새 상류 위반을 만들었으므로 현재 배치와 감지 범위의 한계가 관측됐다.

09:30에는 SVR4/7의 원본7탭이 같으며 신규3기를 더하면82.B가0.000301177pu 낮아진다. 21:45에는 원본탭이 같은데82.A가0.000365524pu 높아져 SVR7만 실패한다. 22:00에는 SVR7 Reg4A가 SVR4보다 한 단계 낮고82.A가0.005747841pu 낮다. 이는 시간·상별 영향이 일정하지 않음을 보인다. 원본 RegControl LDC 보상 감지 전압과 원본 branch terminal P/Q는 저장되지 않아 정량적인 LDC 인과 분해는 UNKNOWN이다. 비보상 winding 전압·전류, 모든 SVR 감지 전압·terminal P/Q·탭, native 후속 전기 해석 이벤트는 보존했다. 개별 탭만 고정한 미분 민감도나 새로운 AC 실험으로 위 인과를 입증했다고 주장하지 않는다.

구현·측정 문제는 별도로 구분했다. 이전 B0 재생의 전압·A·kVA·탭·계획 배열은 같았으나 `current_pu`만 원본 명판 기준과 native110% 기준 사이에서 달랐다. 측정 함수를 원본 기준으로 복원했고 최종 B0 원본15배열 bit-exact 및 독립 명판 전류 검산을 통과했다. B1 입력의 경로 junction 표기 차이는 동일 실제 파일·SHA·바이트 길이 확인으로만 허용했으며 다른 복사본·변조는 거부한다. 이 수정은 실제 장치 정격이나 회로를 변경하지 않았다. 최종 May03 위반은 저장자료 무결성·제어 완료·정격 검사에 통과한 실제 물리 실패다.

## 4. 탭 동작·손실·독립성

추가 SVR은 관측한 SolveSnap 사이 슬롯 내 방향 반전이 0이다. 원본7의 같은 관측 방식 반전은 REF_TIME23회, SVR4 32회, SVR7 30회이며 May02에는13회로 REF_TIME8회보다 많았다. 원본 Reg4 boost와 추가 SVR buck 및 반대 방향 동작을 관측했으므로 무간섭이라고 표시하지 않는다. 모든 슬롯이 수렴했지만 연속시간 진동·전력품질·열 과도현상 인증은 아니다. 117,353행 전체 궤적과270행 제어기·날짜 요약 및 bit-identical gzip를 제공한다. 해당 횟수는 실제 SolveSnap 사이 집계 탭 차이이며 내부 모든 접점 스위칭 횟수를 직접 계측한 값은 아니다.

SVR7은 다섯 날짜 모두 SVR4보다 최대선로부하율이 조금 낮았고 손실 추정치는 하루108.75–109.47kWh 높았다. May03은 SVR4 1,092.387842kWh, SVR7 1,201.607383kWh다. 손실은 슬롯 종료 W×0.25h 합산이며 이벤트 사이 연속 적분이 아니다. BUS50의 손실 이점은 BUS48 대안과의 비교에 한정한다.

Planning/Actual은 동일 코드·하드웨어 규칙을 쓰도록 구현했지만 Fresh 상태는 독립적이다. 이번 실행은 기존 계획의 Actual 재생만 수행했으며 Planning 탭 복사, 미래 Actual 제어 입력, 새 계획 최적화 및 Actual P/Q 수정이 없다. DAYAHEAD/ACTUAL 독립 초기상태 콜드 검증은 새 SVR 계통에서 재최적화한 Planning→Actual E2E PASS를 의미하지 않는다.

## 5. 월간 커버리지와 실행 시간

유효 원계획은 B0 31일/B1 31일/B2 3일, 총65개 정책·날짜다. 5개를 두 구성으로 시험한 뒤 대표 게이트 실패로 나머지60개 유효 계획은 `NOT_TESTED_CANARY_GATE`로 표시했다. B2 나머지28일과 유효한 B3 A1→M1→A2→M2 결과가 없는31일은 `NOT_TESTED`다. 각 구성124개 정책·날짜 행에서 수치가 비어 있는 항목은 미측정이며 PASS 또는0이 아니다. 다른 정책의 계획을 B3에 대입하지 않았다.

최초 B2 May01의 SVR4/7 프로세스 시간은71.400482/70.995723초다. 증거 아카이브·원본 STATIC 게이트·SVR 실제AC 및 SVR4 측 REF_TIME을 합친 시간이다. 최초 날짜 비용을 단순 외삽하면65쌍은 순차154.26분, 이상적3프로세스 병렬51.42분이며 초기 순차 게이트와 IO 경합은 포함하지 않는다. 실제10개 비교의 날짜 프로세스 시간 합계586.425940초, dispatcher 경과400.685071초(6.68분) 후 실패로 중단했다. 전체 월간 완료시간과 남은 실행 ETA는 없다.

외부 dispatcher는 물리 실패를 정확히 저장·중단한 뒤 종료 영수증 생성 시 중복 keyword TypeError를 냈다. 실제10개 결과와 입력·Source 무결성은 모두 유지됐고 별도 읽기 전용 terminal recovery 영수증을 생성했다. 원본 실행 코드와 오류 증거를 보존하고 종료 기록 수정본 v2를 별도 작성했으며 v2로 물리 시험을 재실행하지 않았다. 이 기록 오류는 AC 물리 실패나 게이트 통과로 재분류하지 않는다.

## 6. 산출물과 배포 결정

필수7파일, IEEE123 literal SVG/PNG·좌표·상별 edge 자료, 전체 탭 궤적, 실패 셀·정격·원본과 SVR 탭·입력 SHA, Source·동결·후보선택·TIME 지연·독립 검증·실행 도구를 보존한다. 과거 D-STATCOM921건/단일 STA08 40건, CapControl 실패와 이전 Source Epoch도 별도 기록으로 유지했다. 시험100개 PASS와 독립 파일·시간·전류 검산은 실제 May03 물리 FAIL을 덮지 않는다.

**월간 승인 후보 없음.** SVR7은 이번 표본에서 최악 전압 초과가 작고 최대선로부하율이 낮아 후속 공통 설계 검토 후보로 남긴다. Bus82 상류 감지·전압제어 범위 및 원본 LDC와 직렬 SVR의 간접 상호작용을 다음 공통 Source Epoch에서 검토해야 한다. 특정 날짜의 설정 수정·원본 RegControl 제거 또는 고정·전압 상한 완화로 PASS시키지 않았다. 추가 설비가 필요한지 또는 공통 제어 변경으로 충분한지는 현 시험으로 확정하지 않는다.

새31일 최적화는 Gurobi 호출0·E2E NOT_RUN·배포 HOLD다. 공통 하드웨어 변경을 개발에 사용한 경우 해당 날짜는 Holdout이 아니다. 다음 설계가 실제 대표 및 월간 AC·모델 재생성·독립 Planning/Actual E2E를 통과한 뒤에만 B0→B2→B1→B3 캠페인을 진행할 수 있다.
