# ce30 동결 계획 Actual-only: 5월 3일 신규 상류 전압 실패

SVR4와 SVR7은 모두 월간 공통 전압 0건 승인 조건을 통과하지 못했다. 같은 2025-05-03 B2 동결 계획을 적용한 REF_TIME의 전압 위반 168개 셀은 두 구성에서 모두 해소됐지만, 기존에 안전했던 원본 82번 버스에 각각 2개 **새로운** 상한 위반이 생겼다. 이를 기존 위반의 잔존으로 기록하지 않는다. 선로·변압기 Native NormalAmps, 각 권선 상별 명판 전류, 권선 kVA 초과는 모두 0건이고, 96개 슬롯의 Original7 AUTO·제어 완료·SVR 장치 정격 검사는 통과했다. 전압 실패가 남으므로 하드웨어 동결 영수증은 월간 공통 PASS나 새 Planning–Actual E2E 승인을 의미하지 않는다.

상한은 세 실행 모두 1.05 pu 그대로다. SVR4의 하루 최고전압은 1.050473389634, SVR7은 1.050141371039다. 7개 구성은 4개보다 하루 최고전압을 낮췄지만, 21:45의 A상에는 4개에서 없던 초과를 만들었다. 특정 시각의 개선을 모든 상·시각의 개선으로 일반화할 수 없다.

원본 상별 가지를 독립적으로 추적하면 82번은 Original Reg1과 해당 상의 Original Reg4 아래에 있고, 마지막 원본 가지는 `Line.l82: 81→82`다. BUS83 SVR은 그 다음 `Line.l84: 82→83`의 terminal 1 앞에 삽입돼 원본 83번을 감시한다. 따라서 원본 82번은 BUS83의 탭 비율과 하류 원격 전압 피드백에 직접 포함되지 않는다. 09:30의 SVR4 B상에서 원본 82.B는 1.050382050985인 반면 추가 MV 버스는 1.000306792048, 감시 83.B는 1.001705719832였다. BUS83.B 탭은 0.95로, 물리 하한 0.9에 도달한 상황도 아니다. 하류가 제어 목표 안에 정착해도 상류 원본 노드가 안전해지는 것은 아니다. 단, 같은 망의 전류·전력 흐름을 통해 상류 전압이 간접적으로 바뀔 수 있으므로 ‘영향이 전혀 없다’고 해석하지 않는다.

이 비교는 같은 원본 P/Q·위치·Actual 외생 입력에 동결 하드웨어를 추가한 **96슬롯 전체 자동제어 개입**이다. 09:30에는 4개와 7개의 Original7 최종 탭이 모두 같고, 새 3개를 추가한 7개의 82.B 전압이 0.000301176718 낮다. 21:45에도 Original7 최종 탭은 같지만 7개의 82.A는 0.000365523722 높다. 22:00에는 7개의 Original Reg4A 탭이 4개보다 한 단 낮고, 82.A가 0.005747840560 낮다. REF_TIME 대비 09:30 SVR4에서는 Original Reg1 탭도 한 단 높다. 이 관측은 자동 탭 이력과 흐름의 상호작용을 보여 준다. 개별 장치 손실·Q 흐름·특정 탭 하나의 기여나 제어 게인의 단독 원인은 분리 식별되지 않았으므로, 국소 탭 미분값이나 유일 원인으로 주장하지 않는다.

SOURCE는 `ce30af2a74d9d2b6a2f2a33fee7a690927752f940f94bd466218075ba34cbf04`다. SVR4 `.06`과 SVR7 `.02`의 기존 4개 장치 물리·제어 DTO는 정확히 같고, 그 canonical SHA는 `50107089d25566ad97141dcc2a8170fc4c8c7fdecc2cf8513988e70bfed94503`이다. 원본 7개 RegControl 파라미터와 4개 Fixed-ON 커패시터, 동결 MESS P/Q·위치·PCC 입력의 96슬롯 동일성을 검사했다. 각 실행은 같은 Source 초기 상태에서 별도 컨텍스트로 시작했고 하루 안에서만 상태를 이어 갔다. Actual P/Q 보정·Planning 재최적화·Native optimizer 호출은 0이다. 보존 실행의 native TIME SolveSnap 수는 REF_TIME 193, SVR4 608, SVR7 615이며, 본 감사는 추가 DSS compile/solve를 실행하지 않았다.

Original7의 감시 권선 전압 크기, PT 환산 전압, 전류 크기, 실제 탭과 파라미터를 CSV로 남겼다. 그러나 원본 RegControl의 복소 V/I, LDC 보상 후 센서 전압, 원본 변압기 단자 P/Q는 이 저장 자료에 없으므로 **UNKNOWN**이다. 원본 보상 센서가 제어 대역을 벗어났다는 추정값을 만들지 않았다. 추가 SVR은 실제 감시 전압, 두 단자의 signed P/Q·전류·kVA·손실·탭을 전 슬롯 저장했다. Original7의 같은 슬롯 안 관측 탭 방향 반전은 5월 3일 REF_TIME 6회, SVR4 9회, SVR7 9회였고, 추가 SVR의 반전은 0회였다. 유한한 원본 제어 반전과 상호작용이 존재한다. 이는 96개 슬롯 끝의 정착과 native 큐 이후 탭 관측이며 연속 시간·전자기 과도 안정성 인증은 아니다.

ce30의 5개 실행일(B0 5월 1일, B1 5월 28일, B2 5월 1·2·3일)에서 신규 BUS79·BUS108·BUS50의 실제 signed 단자 2 P를 각각 1,440회, 합계 4,320회 검사했다. 단자 2로 들어오는 양의 유효전력은 0회였다. 세 장치의 단자 2 P 범위는 각각 −45.901410…−3.049444, −146.623004…−4.437322, −51.574631…−6.097040 kW다. 따라서 신규 3개 장치의 실제 역송 관측 상태는 `REVERSE_REAL_POWER_NOT_OBSERVED`다. Q 부호로 유효전력 역송을 대신 판정하거나, 별도 합성 부호 실험을 실제 날짜의 양방향 승인으로 바꾸지 않는다. 각 장치의 로컬 정격·추가 노드 전압 검사는 통과했지만, 5월 3일 전체 망 실패는 그대로 유지한다.

현재 7개는 기존 4개보다 넓은 직접 연결 범위를 가진 동결 하드웨어 후보이며 공통 승인 후보로는 미통과 상태다. Canary gate 이후 실행하지 않은 유효 입력은 `NOT_TESTED_CANARY_GATE`, 원래 동결 계획이 없는 입력은 `NOT_TESTED`로 보존해야 한다. 게인·용량·탭 설정·전압 제한을 바꾸거나 탭을 고정·비활성화한 결과는 이 보고서에 사용하지 않았다. 새 Planning E2E·전체 5월·블라인드 검증 성공을 주장하지 않는다.
