Research only; optimizer_use_allowed=false. No request feature was certified from the archived accounting snapshot. This package takes no job-specific predictor, so it estimates an unconditional total-runtime distribution. It is not approved for V42.

Install requirements, then run inference_example.py. RuntimeProvider() refuses unapproved use by default; allow_research=True explicitly enables isolated diagnostics. No training data, cached job predictions, pandas, GPU or original worktree is needed for inference. requested_seconds is only an unverified echo, never a model feature or cap.
