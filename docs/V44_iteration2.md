## Persistent admission and ordering

The scheduled supervisor uses its own nonblocking single-owner OS lock. While
B2 runs, only preparation/light tests operate. The authoritative B2 state is
resolved through the active equipment registry, including the new B2 weather
recovery controller. Dispatch requires all ten dates terminal, COMPLETE phase,
no pending retries/resume, all related PIDs dead, all six original OS locks
available, no unreconciled Native inflight, and preserved results/checkpoints.
A zero-worker snapshot alone never opens this gate. Original B2 files are not
modified by this experiment. Only after this gate does the new coordinator
hold the six original locks and start serial Planning across all31 dates.

Every stage gets an immutable attempt and request reservation. Completed core
checkpoints and all sources/files are reverified before reuse. An interrupted M
can restore the same binary Case and retain measured K48 and Joint accounts.
An interrupted A with a reconciled ledger may rebuild the exact same stage using
the existing r046 inherited-budget adapter, retaining both total A and Phase-I
costs. A live Solver tree cannot be restored. Unmeasured/inflight calls, source
drift, exhausted budgets or unsupported checkpoints block that date for a
diagnosed repair; they cannot create a fresh uncharged account. Failed stage
evidence stays intact; other dates continue. No previous-stage fallback/PASS
override is permitted. A receipt without a public terminal result can recover
its verified completed stage without another solve, preserving old failures.

Actual cannot start until all31 M4 freezes and the aggregate barrier verify.
Then independent per-date processes run original Actual120 followed by separate
Fresh120. The unchanged Actual engine has no Planning optimization; an outer
Native-zero guard reinforces this. Final acceptance includes original execution,
all120 independent physical measurements (including both transformer terminals,
currents and native SVR/TIME controls), SOC/routes/PCS, capacity/jobs/Known policy
and QoS intentional delay/migration budgets. No result flag can bypass a gate.

## Resources, monitor and comparison

Actual has a rolling ceiling of seven original P-logical CPU slots. The first
complete Actual/Fresh calibrates process-tree RSS. Admission reserves 6 GiB and
uses at least 2 GiB per additional worker or twice observed peak plus1 GiB,
whichever is larger; calibration starts with one6 GiB worker. Memory/disk
shortages stop new dispatch until resources recover. Planning requires8 GiB
available plus6 GiB reserve and16 GiB free disk; Actual requires4 GiB disk.

seven never claims this machine can safely fit seven at every moment. No worker
is killed to satisfy admission. A supervisor restart first waits for surviving
workers, preserves partial Actual, and uses a fresh independent native engine
only for an incomplete Actual stage. Complete results are hash-verified/reused.
