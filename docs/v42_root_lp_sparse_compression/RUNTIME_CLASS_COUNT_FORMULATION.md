# Exact completion common-subexpression factorization

For a certified physical/scientific class g, site k and physical finish time t, introduce a continuous auxiliary C[g,k,t] bounded by the class cardinality and the equality C = sum of all relevant f0 and f1 completion expressions. An integer type is unnecessary: the defining equality makes the count integral whenever the underlying path assignment is integral, and continuous type preserves the continuous relaxation.

Each completion event's entire downstream coefficient vector is computed by the inherited `completion_risk`: the adjusted end uses the frozen nominal completion offset, gamma90, GPU gang and survival kernel. Grouping requires equality of the full vector, with no averaging or tolerance. Factorization replaces alpha times each event by alpha times C and adds one sparse equality. A mismatching vector fails closed rather than reusing a representative.

Forward mapping assigns C its exact sum. Reverse mapping projects out C using the equality, yielding exactly the original downstream equations in both integer and continuous relaxations. Bounds are redundant valid bounds because each class has exactly N complete individual paths. No Runtime reserve/headroom or risk authority changes.
