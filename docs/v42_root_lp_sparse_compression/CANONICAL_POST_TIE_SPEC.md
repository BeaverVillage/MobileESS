# Canonical representative after scientific locks

There are exactly six scientific lexicographic levels: rho, reserve shortfall, CC4 reference deviation, migration count, shift slots, and prestart placement changes. The old physical-event rank is not a scientific level. Removing its bounded rank auxiliaries projects onto the same physical feasible set; no rank objective participates in a scientific lock.

After optimization, extract complete individual physical trajectories using the inherited validator. Within each independently certified scientific-equivalence class, sort trajectories by the inherited `Option` physical tuple ordering (start, initial site, full service segments, checkpoint, transfer timing, destination, restart and WAN bytes). Assign that sorted multiset to sorted stable UIDs. Jobs outside such classes retain their extracted trajectory. This only permutes identical jobs; it preserves every site/time GPU quantity, every fixed link/time WAN quantity, active-transfer count, exact completion-risk coefficient, grid control and all six scientific objective values.

Repeatability means that the same aggregate solution reconstructs identically on repeated calls. It does not assert that separate solver runs select the same aggregate optimum. This canonical assignment changes deterministic representative selection and is not claimed to minimize the old event-rank objective. Scientific optimum sets are unchanged.

An interrupted P1 run may provide a validated incumbent, but canonical extraction from that incumbent is not called a completed six-level lexicographic optimum. Final locks follow the inherited protocol and are applied only after an OPTIMAL solve at a level.
