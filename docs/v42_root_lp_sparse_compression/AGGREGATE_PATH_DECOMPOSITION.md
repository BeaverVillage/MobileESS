# Aggregate to individual certificate

The staying histogram explicitly represents complete fixed-duration paths. Integer Y[k,s]=n creates n distinct jobs with identical full segments (k,s,s+D); it never creates fractions, service fragments or a pooled service quota. Optional migration lanes contribute one individually validated complete path each. Exact cardinality rejects a multiset with a different number of paths.

The inherited individual validator checks every reconstructed UID against its original Job, ServiceBoundary and Resources. Resource sums and the full completion-risk vector are recomputed from the reconstructed multiset. Stable UID and physical signature ordering supplies deterministic assignment. Bounded exhaustive old-to-new tests include all UID permutations; reverse integer pools are compared modulo only the certified identical-job symmetry.
