============================================================

Runtime-vNext14R2 is closed.

- private RADDiT exporter
- hidden timestamp stripping code

- deleted/private execution manifests

V14R2 evidence remains preserved.

The project decision is now:

    Do NOT depend on the distributed RADDiT embedding representation
    for V42 deployment.

Instead:

    adopt the publicly documented RADDiT submission-information concept

and construct our own:

    deterministic
    reproducible
    submission-time-only
    future-callable

semantic representation.

This new representation must be usable by the same code for:

1. historical Kestrel training/replay
2. D-1 already-submitted jobs
3. D-day newly arriving jobs
4. future V42 inference

The new representation is:

    RADDiT-derived / RADDiT-inspired open semantic representation

NOT:

    the original RADDiT distributed embedding.

Do not claim otherwise in paper-facing text.


============================================================
1. SCIENTIFIC MOTIVATION
============================================================

V13 showed that request descriptors plus observable current workload state
were not sufficient for robust per-job Q90 Runtime forecasting.

Best S4:

    pooled Q90 = 91.84%
    min-fold = 70.70%
    >4h = 69.72%
    >12h = 64.25%
    >24h = 46.88%

V14–V14R2 then identified richer submission-side semantic information
associated with the RADDiT methodology.

Public RADDiT semantic input family:

    user
    account
    partition
    job_type
    name
    qos
    submit_line
    script

The new hypothesis is:

    Reproducible submission-side workload identity/composition information
    may improve Runtime temporal robustness and CC4 future-workload prediction.

This is a predictive hypothesis.

Do NOT claim causal effects or hidden-variable proof.

============================================================

Primary representation name:

SEM_COOCCUR32_V1

Design goal:

- deterministic
- CPU-callable
- no private model
- no remote API
- no future information
- train/replay/inference same implementation

============================================================
11. PRIMARY SEMANTIC TRANSFORM
============================================================

Use this frozen structure:

Stage A:
    canonical token set

Stage B:
    sklearn FeatureHasher

Frozen parameters:

    n_features = 262144
    input_type = "string"
    alternate_sign = False

Use binary token presence where appropriate.

Stage C:
    TruncatedSVD

    n_components = 32
    random_state = 1401

SVD must be fit using TRAIN only for each temporal fold.

VALID/CAL/test/new jobs are transform-only.

Output:

    sem_00 ... sem_31

Call this:

    SEM_COOCCUR32_V1

Reason:

This captures submission-field co-occurrence/workload identity
without requiring RADDiT's private embedding coordinates.
