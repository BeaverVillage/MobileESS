0. PURPOSE
============================================================

Do NOT train any new Runtime ML model.

PR #94 established that no Q50-Q90 scalar interpolation satisfied the
previous preregistered 90% reliability criterion with an acceptable
runtime time ratio.

However, the intended V42 Runtime interface has now changed:

    Q50 = nominal individual-job runtime used in Planning

    Planning = separately protects against runtime overrun using
               pooled runtime-overrun reserve/headroom

    Actual = does NOT add a duplicate overrun reserve;
             an observed RUNNING job keeps occupying its actual GPU gang
             until it physically completes

Therefore we need to characterize Q50 itself correctly.

Primary question:

    Is V9_D2_EXTREME_1P0_NONE Q50 a defensible nominal Runtime predictor?

In particular calculate its empirical Q50 coverage and temporal stability.

This is a frozen-prediction audit only.

5. PRIMARY NEW METRIC: Q50 COVERAGE
============================================================

For each model define empirical Q50 coverage as:

    C50 =
        (1/N) * sum_j I(T_actual_j <= Q50_j)

where:

    T_actual_j = realized runtime
    Q50_j      = frozen predicted median runtime

Use <= consistently.

A calibrated conditional median should have empirical coverage near 0.50,
although exact finite-sample pooled coverage need not equal exactly 50%.

Report:

    pooled Q50 coverage
    fold-1 Q50 coverage
    fold-2 Q50 coverage
    fold-3 Q50 coverage
    fold-4 Q50 coverage
    fold-5 Q50 coverage

Also report:

    min-fold Q50 coverage
    max-fold Q50 coverage
    std across fold coverages

============================================================
16. IMPORTANT INTERPRETATION OF Q50 COVERAGE
============================================================

Do not call 50% coverage "bad."

For a correctly calibrated median:

    Q50 coverage ~= 50%

is expected.

Likewise:

    Q50 coverage >> 50%

means the nominal median prediction is conservative / high.

    Q50 coverage << 50%

means it is systematically low / underpredictive.

The desired Planning robustness does NOT come from forcing Q50 coverage
to 90%.

Planning robustness will be supplied separately by runtime-overrun reserve.
