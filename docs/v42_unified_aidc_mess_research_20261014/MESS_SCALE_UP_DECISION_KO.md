# MESS 규모 확대 판단

원본 후보지는 IDC01–IDC12와 STA01–STA12의 24개이다. S1은 MESS01·MESS03과 STA01·STA08·IDC01·IDC11·STA12를 사용한다. 초기 위치, AIDC 공존, 서로 다른 전기적 경로와 상류·하류 위치를 실행 전에 고정했다. 원본 이동 링크·ETA·이동에너지와 Full96 축을 유지한다.

비활성 MESS02·MESS04는 설비에서 삭제하지 않으며, 원본 FULL STAY의 0 kW와 비영(非零) Q, SOC 760 kWh를 보존한다. 이번 코드가 원본 물리 검증과 현재 계통 행을 다시 검사하며, 과거 PR223 전압 인증을 복사하지 않는다.

S1 모델 구성은 79.336초, 836244행·7711변수·4717개 이진변수·23258846개 nonzero였다. Presolve 8.39초 후 154345행·7672변수로 줄었으나 Root LP는 17.57초 진행한 뒤 시간 제한으로 중단됐다. Native Runtime은 30.241초이며 요청 30초보다 0.241초 길었다. 현재 FULL 검증 UB는 0.641265966974028, 축소 문제 Global LB는 0.466196267205184, Gap은 27.3006%이다. 최선 이동 FULL 해는 발견하지 못했다. 전체 4대의 route/SOC/PCS와 비활성 차량의 P/Q 일치는 PASS였다. 피크 RSS 2.893 GB, 피크 Private Commit 4.172 GB를 기록했다.

소스 정차 시작점과 최종 UB의 차이는 RHO 초기화의 1e-9 안전 여유이며, 실제 경로·P/Q 개선의 성과로 주장하지 않는다. 3% Gap은 실패했고 원본 4대·24개 Global 인증도 없다.

현재 S1 상태는 REDUCED_FULL_FEASIBLE이다. S2–S7은 NOT_RUN이다. 차량 수와 후보지 수 중 무엇이 더 큰 실제 병목인지는 동일 조건 실측 전에는 판단할 수 없다. 모델 크기 예상치는 계측이 아니다. 원본 계통 행은 규모 축소에도 모두 남으므로, 경로·P/Q 변수를 줄여도 계통 행 구성 시간이 지배할 수 있다.

S1의 현재 FULL 해와 공유 Native 원장·메모리를 확인한 뒤에만 다음 규모를 선택한다. 후보 경로 제한 Bound를 Global LB로 승격하거나 3% Gap을 임의 인증하지 않는다. 본 실험의 AIDC anchor는 명시적 과거 진단 anchor이며 새 E60 A1 인증이 아니다.
