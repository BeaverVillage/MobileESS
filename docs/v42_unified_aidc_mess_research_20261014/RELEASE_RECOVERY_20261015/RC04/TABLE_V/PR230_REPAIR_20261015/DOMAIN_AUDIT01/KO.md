# PR230 E1/D0 독립 Native0 도메인 감사

원본 typed E1 발급기 재발급과 별도 membership·window·budget 산술이 저장 receipts와 모두 일치했다. 992개 PENDING UID의 3,667개 시작 슬롯 복원을 독립 확인했다(MEMBER 281 / NONMEMBER 711). 양수 잔여서비스 1,555 UID, checkpoint 권한 454 UID와 D0 이전 시작 금지, 원본 hard release/deadline, 호환 site·GPU·rack·WAN 수치, 모든 STAY 시작의 전체 서비스와 carry를 검사했다. Q50 만료 RUNNING 69 UID / 187 GPU의 D0 현재 슬롯 물리 점유도 보존됐다.

독립 descriptor SHA는 실제 Native matrix/column geometry SHA와 구별한다. 기존 certificate/result의 Matrix·Domain binding은 서로 일치하지만, matrix/column/objective 배열이 보존되지 않아 이번 Native0 감사에서는 실제 geometry 및 Objective SHA를 독립 재계산하지 않았다. FULL-feasible, DW 하한, 정수해 또는 Global Gap 인증이 아니다.

원본 frozen Source와 현재 작업 소스의 byte 차이 0건은 JSON에 개별 기록했다. 기존 입력·Raw는 변경하지 않았으며 Native/model build/geometry materialization/Actual/AC 호출은 모두 0회다. R1 유지, R2 HOLD, P2 0회를 확인했다.
