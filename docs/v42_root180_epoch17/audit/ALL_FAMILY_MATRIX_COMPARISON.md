## Growth attribution and input axes

* Hardware changed from 263 line + 120 transformer phases to the same 263 line + 153 transformer phases, with 386 → 419 physical voltage nodes. The 33 new transformer phases are enumerated in `MODEL_GROWTH_AND_INPUT_AXES.json`.
* LDC duplicates 419 voltage nodes to 838 endpoints. Its two stored voltage-coefficient halves are bitwise identical. Static presolve already reduces 80,448 → 40,128 rows per voltage inequality direction; the duplication alone does not explain the final growth.
* Old lossless downstream-flow bindings were sparse. Current independently measured native AUTO/TIME secants produce dense cross-control P/Q, current, and loss/control responses. Actual line P/Q definitions rise from about 4.8 to about 49 entries including the auxiliary while the line count remains unchanged. Exact repeated-auxiliary detection exists in both paths; the underlying tensors differ.
* Historical cost-gated transformer auxiliaries were 576 each before presolve, 288 each afterwards. Dense current tensors activate 14,688 each. Historical F0 transformer faces were already 73,728 below the raw 184,320, while current raw 235,008 = 153 × 96 × 16. Hardware by itself adds 50,688 raw transformer faces.
* The named 60-control axis is identical: 12 AIDC + 24 MESS-P + 24 MESS-Q. Historical accepted A1 and current independent B2 fixed-AIDC inputs differ in 1,050 / 1,152 entries, with maximum 54.7723975641307 kW. These fixed inputs change constants/RHS and proof margins; actual regenerated tensor support explains coefficient density.
* Every checked original route/PCS/SOC/mode/energy-balance/injection block is bitwise identical in coefficients, support, RHS, senses and row names. Historical source-node bound propagation fixed four time-zero activity binaries before C2; Epoch16 omitted it.
* Both C3A passes really delete 53,652 PCS + 17,884 connected-Q + 4 terminal-location rows, or 71,540 rows / 232,588 NNZ. Epoch16 omitted the historical pre-C2 route/PCS/SOC security support pass, leaving far more security rows and response auxiliaries. Fresh Source17 certificates, rather than historical row IDs, are required for further deletion.
