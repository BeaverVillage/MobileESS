# 한 슬롯 원본 정수 물리집합과 독립 타당성 증명

이 문서는 PR162의 과학적 물리를 그대로 읽어 다음 네 부등식 계열의 전역 정수 타당성을 증명한다. 후보 생성기와 독립 검증기의 구현은 분리되어 있다. `independent_hull.py`는 생산 강화 생성기를 가져오거나 호출하지 않는다. 수치 최적화, solver API 호출, 매개변수 변경도 하지 않는다.

## 1. 원본 의미와 읽기 전용 권위

원본 모델 `v42_native/mess.py`의 시간 DAG에는 단위 MESS마다 시작점에서 종료 시간까지 보내는 단위 유량이 있고, 원본 arc는 이진이다. `STAY` arc는 한 사이트의 `[t,t+1)` 연결 상태다. 이동 arc는 출발에서 연결 가능 시간까지의 구간을 건너뛴다. 경로 중 이동/도착 후 연결 전 대기 구간에서는 P/Q가 0이다. Q는 charge_mode와 독립이다. 전역 `charge_mode[m,t]`는 해당 단위·슬롯의 유효전력 충전/방전 방향 하나를 정한다.

독립 검증기는 원본 `FULL_DATA.npz`, `FULL_A.npz`의 고정 SHA-256을 확인한다. 저장된 C2 제거 인증서와 retained axis만으로 좌표 inverse를 다시 구성한다. 생산 강화 생성기가 사용하는 `analyze_point.expr`를 호출하지 않는다. 원본 미생성 도달 불가능 arc/PQ 변수는 원본 생성 규칙에 따라 0으로 읽는다. 원본 arc 이름은 추측한 이진 family 분류가 아니라 원본 시간 DAG의 순서 및 권위와 결합한다.

PCS의 삼각함수 대칭성이나 실수 이상화를 가정하지 않는다. PCS16 행의 **실제 저장된 binary64 계수**를 원본 행렬에서 읽고 `Fraction.from_float`로 정확히 해석한다. SOC 동역학의 충·방전 계수 및 출발 이동 에너지 계수도 원본 행렬에서 읽는다. 이 해석은 저장된 모델의 수학적 선형 제약을 나타낸다.

## 2. 원본 정수 경로에서 성립하는 사실

단위 DAG의 이진 단위 유량은 하나의 시작–종료 경로다. DAG이므로 순환 유량은 없고, 선택된 노드에서 incoming/outgoing의 정수 유량 보존과 단위 공급은 분기 가능한 유량을 1로 제한한다. 따라서 임의의 시간 cut을 가로지르는 선택된 arc는 정확히 하나다. 그 arc가 stay이면 해당 사이트만 연결되고, move/transit/wait이면 모든 사이트에서 미연결이다.

단위 `m`, 시간 `t`, 사이트 `s`에 대해 `y_s`를 stay arc, `c_s,d_s`를 각각 충전·방전 전력, `z`를 전역 charge_mode라 하자. `L=300 kW`는 권위에서 읽은 원본 P_limit이다. 원본 정수 물리는 다음을 포함한다.

* `y_s,z ∈ {0,1}`, `Σ_s y_s ∈ {0,1}`;
* `c_s,d_s ≥ 0`, `c_s ≤ L y_s`, `d_s ≤ L y_s`;
* `c_s ≤ L z`, `d_s ≤ L(1-z)`;
* `z=1`이면 모든 `d_s=0`; `z=0`이면 모든 `c_s=0`;
* 연결된 사이트는 최대 하나다.

이 사실들은 SOC, 원본 PCS16, grid의 추가 제약을 포함하는 모든 정수 해에서도 성립한다. 다음 증명은 추가 제약을 버려도 성립하므로 원본 정수 feasible set 전체에 대한 타당성을 갖는다.

## 3. 후보 계열의 보편 증명

`AGGREGATE_CHARGE_MODE`: `Σ_s c_s ≤ L z`.

`z=0`이면 각 `c_s=0`이므로 좌변은 0이다. `z=1`이면 하나 이하의 사이트만 연결되어 그 사이트의 `c_s≤L`이고 나머지는 0이다. 두 경우 모두 성립한다.

`AGGREGATE_DISCHARGE_MODE`: `Σ_s d_s ≤ L(1-z)`.

`z=1`이면 모든 방전이 0이고, `z=0`이면 하나 이하 연결 사이트의 방전만 가능하며 원본 전력 상한이 L이다.

`AGGREGATE_CONNECTED_POWER`: `Σ_s(c_s+d_s) ≤ L Σ_s y_s`.

`Σy=0`이면 모든 전력이 0이다. `Σy=1`이면 하나의 사이트에서만 전력이 존재한다. 전역 이진 방향 때문에 충전/방전 중 하나만 양수일 수 있고, 그 전력은 L 이하이다.

`LOCAL_CONNECTED_POWER`: `c_s+d_s ≤ L y_s`.

`y_s=0`이면 두 전력은 0이다. `y_s=1`이면 이진 방향에 따라 둘 중 하나가 0이고 다른 하나는 L 이하이다.

계수, 사이트, 슬롯, 단위는 독립 검증기가 위 식과 원본 권위에서 다시 구성한다. 저장 inverse로 C3 좌표에 옮긴 **전체 계수와 RHS가 정확히 일치**해야 후보를 승인한다. 형식을 따르지 않는 계수나 RHS는 거부한다. LP 관측값으로 계수를 맞추거나 학습하지 않는다.

## 4. 한 슬롯 국소 정수 상태와 연속 꼭짓점의 정확한 열거

각 감사 블록은 MESS 하나와 슬롯 하나다. 초기 사이트에서 원본 DAG를 따라 도달 가능한 모든 arc 중 해당 슬롯을 가로지르는 arc를 전부 열거한다.

* `STAY_CONNECTED`: 연결 사이트, stay arc, charge_mode 0/1;
* `MOVE_DEPARTURE`: 출발 이동 route, 원본 출발 에너지, charge_mode 0/1;
* `TRANSIT_OR_PRECONNECT_WAIT`: 진행 중 route와 그 구간, charge_mode 0/1.

각 stay·mode 상태의 연속 변수는 `(p≥0,Q,E_t)` 세 개다. mode에 따라 `p`는 충전 또는 방전 전력이다. `E_{t+1}=E_t+αp-travel`을 원본 저장된 energy_balance 계수로 정확히 대입한다. `0≤p≤L`, 원본 Q 상한, 원본 16 PCS 면, 두 SOC 경계 상한/하한을 모두 포함한다. `t=0`에서는 원본 initial_SOC를, `t=95`에서는 원본 terminal_SOC를 고정한다.

꼭짓점은 모든 독립 활성 평면 세 개의 교점을 유리수 Gaussian elimination으로 구한 뒤 모든 반공간을 유리수로 다시 확인해 중복 제거한다. 유계 3차원 다면체의 모든 꼭짓점은 활성 법선의 rank가 3이므로 이 방법은 빠짐없이 열거한다. endpoint나 미연결 상태처럼 차원이 줄어도 고정 경계의 양쪽 면을 포함한다. 미연결 상태는 `p=Q=0`이므로 정확한 SOC 구간의 양 끝점으로 직접 열거한다. SOC 경계와 이동 에너지를 동시에 만족하지 못하는 상태는 빈 집합으로 기록한다.

모든 열거된 연속 꼭짓점에 네 계열의 원본 공간 부등식을 다시 평가한다. `LOCAL_CONNECTED_POWER`는 선택된 연결 사이트에 대한 평가와 다른 사이트의 `0≤0`을 함께 포괄한다. 비양수 유리수 잔차만 허용한다. 선형 부등식은 다면체 모든 꼭짓점에서 성립하면 그 다면체 전체에서 성립하고, 각 정수 disjunction에서 성립하면 그 convex hull에서도 성립한다.

## 5. 정확한 범위와 한계

열거는 **원본 한 슬롯 제약에 대한 정확한 각 정수 상태 연속 다면체**다. 전체 96슬롯 이전/이후 SOC 경로, grid coupling, 전체 경로의 terminal reachability를 부과한 정확한 global projection은 아니다. endpoint를 제외한 경계 SOC는 원본 bounds 안에서 자유롭게 둔다. 따라서 이 국소 convex hull은 원본 global 정수 해의 해당 projection을 포함하는 **보수적인 국소 hull**이다.

열거된 state 중 일부가 미래/과거 SOC 또는 grid 때문에 전체 schedule로 확장 불가능해도 그것을 포함하는 것은 타당성 증명에 안전하다. 여기에 타당한 부등식은 더 작은 원본 global feasible set에도 타당하다. 반대로 LP가 이 국소 hull 안에 있다는 결과만으로 global integrality gap이 설명되거나 원본 LP가 ideal이라고 주장할 수 없다. 이 검증기 자체는 LP hull membership 최적화를 수행하지 않는다.

감사 블록은 가능한 경우 분수 census에서 선택하며, census가 없으면 권위 증명용 블록을 사용한다고 기록한다. 관측되지 않은 LP 분수 패턴이나 gap 원인을 추정하지 않는다. 2–4슬롯이나 전역 일정 열거, 다른 해법 실행은 이 독립 증명에 포함하지 않는다.

## 6. 기존 start, 정수집합과 목적 보존

각 승인 후보를 저장된 검증 start에 유리수로 평가한다. 시작 벡터의 binary64 저장값을 정확히 쓰며 원본 `1e-8` numerical tolerance를 바꾸지 않는다. 허용오차 내 만족은 수치 start replay이고, 전역 정수 타당성의 근거는 위 증명이다.

승인되는 부등식은 모든 원본 정수 feasible point에서 성립한다. 원본 행·열·경계·과학 물리를 유지하고 이 행만 추가하면 정수 feasible set이 정확히 동일하다. 목적 함수 P1/P2를 변경하지 않으므로 모든 정수 feasible point에서 원본 P1/P2 값도 동일하다. 부등식의 LP 위반 여부와 bound 개선 여부는 부모 작업의 별도 진단이며 이 문서는 그 결과를 선결하지 않는다.
