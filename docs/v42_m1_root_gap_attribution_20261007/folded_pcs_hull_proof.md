# 원본 binary64 PCS와 이진 방향의 접힌 국소 hull

`folded_pcs_hull.py`는 추가 최적화 없이 원본 `FULL_A.npz`의 실제 저장된 PCS16 계수로 두 방향의 한 사이트 전력 다면체를 정확히 열거한다. 원본 전력 상한은 300 kW, Q 상한은 ±400 kvar이다. `charge_mode=1`일 때 원본 유효전력 `P=Pdis−Pch`는 `−p`이고, `charge_mode=0`에서는 `+p`이다. 각 방향에서 `0≤p≤300`과 원본 16 PCS 반공간의 모든 독립 두 면 교점을 유리수로 구한 다음 모든 면을 다시 확인한다. 삼각함수의 정확한 대칭을 가정하지 않는다.

두 다면체를 `(p=|P|,Q)` 좌표로 옮긴 vertex union의 정확한 2차원 convex hull을 monotone-chain으로 구한다. CCW 인접 꼭짓점 `v,w`의 외부 법선은 `(α,β)=(w_Q−v_Q,v_p−w_p)`이고 `γ=αv_p+βv_Q`이다. 이를 `max(|α|,|β|)`로 나누어 스케일을 정한다. 원본 정수 방향은 충전/방전 중 하나만 가능하므로 `p=Pch+Pdis`이고, 모든 원본 정수 연결 상태에서 이 hull의 각 면이 성립한다.

연결 변수가 `y`인 전역 정수 상태에 대한 부등식은 `α(Pch+Pdis)+βQ≤γy`이다. `y=1`이면 앞의 두 원본 mode 다면체 중 하나에 속한다. `y=0`이면 원본 connected 제약 때문에 Pch/Pdis/Q가 모두 0이다. `γ≥0`인 emitted plane만 사용하면 미연결 상태 역시 만족한다. SOC 및 grid 제약은 이 전력 다면체를 줄일 뿐이므로 이를 생략한 hull로부터 얻은 부등식은 모든 원본 global 정수 feasible point에도 타당하다. 글로벌 schedule 또는 SOC hull이 완전히 기술되었다는 주장은 하지 않는다.

## 저장 계수의 외향 반올림

정확한 유리수 면을 binary64 행으로 직접 반올림하면 극미한 위반을 만들 수 있으므로 다음 보상을 계산한다. 저장되는 `a=float(α)`, `b=float(β)`에 대해 `δa=a−α`, `δb=b−β`를 정확한 binary64 유리수로 구한다. 원본 영역 `0≤p≤L`, `|Q|≤S`에서 계수 반올림이 좌변을 높일 수 있는 상한은 `max(0,δa)L+|δb|S`이다. RHS를 이만큼 늘린 뒤 이를 **위쪽 binary64 방향으로** 반올림한다. 따라서 저장되는 `g`는 `γ+max(0,δa)L+|δb|S` 이상이다.

원본 mode별 모든 꼭짓점에서 실제 저장된 `(a,b,g)`의 잔차를 유리수로 재평가하고 최대값이 0 이하인지 확인한다. 원본 16 faces의 미세한 비대칭도 이 검증에 포함된다. 이 조정은 새로운 과학적 근사나 물리 변경이 아니다. 원본 정수 집합을 포함하는 정확히 타당한 부등식 행을 저장하기 위한 증명된 외향 계수 선택이다.

`verify_folded_candidate`는 선택된 **그 단위·사이트·슬롯**의 원본 PCS 계수를 읽어 양 mode의 모든 꼭짓점을 재열거하고 실제 후보 행을 확인한다. 기준 블록의 계수가 모든 블록에 같다고 추측하지 않는다. 저장 inverse에서 후보의 C3 전체 계수 및 RHS를 독립적으로 복원하고, 기존 start를 원본 `1e-8` tolerance로 평가한다. 생산 생성기를 호출하지 않는다.

이 모듈의 계산은 타당성 후보 조사다. 실제 LP 위반이나 bound 개선이 관측되어 채택되었다는 의미는 아니다. 부모 진단에서 위반이 확인된 작은 결정론적 집합만 고려해야 한다. 원본 행 삭제, 목적 변경, 물리 변경은 필요하지 않다.
