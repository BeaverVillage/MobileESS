# Candidate-domain restoration rule under validation

1. Replay the complete S0 witness. If PASS, return STOP_AT_S0 and reuse its five
   original receipts with provenance. No expansion is performed.
2. Otherwise require an independent exact S0 infeasibility proof. An unproven
   TIME_LIMIT or INCONCLUSIVE result does not authorize restoration.
3. Stream the causally known physical omitted-option universe, preserving original
   scientific classes/counts, protection, service, Runtime, capacities, WAN,
   checkpoint/restart, compatibility and representation completion limits.
4. Price each option against signed exact original row multipliers, including
   class cardinality. Negative signed new-column coefficient can lower the
   certificate's bound minimum; zero/positive/unsupported effects are separately
   neutral/worsening/unknown. No small residual is discarded.
5. Advance deterministic same-site ranks before compatible-site/prestart and
   migration shells. Reprice against each newly verified restricted certificate.
   Never activate the entire physical universe in the native model.
6. A small pre-WAN **necessary resource projection** may select candidate sets.
   It keeps every class count. For paths with checkpoint pause it retains only
   guaranteed source occupancy through the earliest supported checkpoint; later
   occupancy is relaxed. Its feasible point is not an A1 witness. Neither its
   feasible rank nor its selection optimum is a full-model minimality claim.
7. Full unchanged A1 LP precedes full A1 integer feasibility. Replay all captured
   original rows/bounds/integrality and physical options/Runtime/grid. Production
   acceptance additionally requires verified exact compression and all five
   stages. Stop expansion once full integer feasibility is independently proved.
8. Every earlier lex objective requires a valid bound proof; unresolved minima
   cannot be called MINIMAL_PRESCREENING_EXPANSION_FEASIBLE. No global minimum
   claim follows from one certificate or one necessary-only projection.
9. Freeze ADAPTIVE_MINIMAL_PRESCREENING_V1 only after both development cases have
   validated integer-feasible minimal domains. Until then normal four-pass A1,
   fixed Actual/Fresh and production adoption remain gated off.

The generic controller has no date-specific candidate list. This document does
not declare the experimental rule validated or frozen.
